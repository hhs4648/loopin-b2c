## 3. 모든 유형에 공통인 흐름 (21번 기준)

1. 지문 한눈에 미리보기 → 큰 버튼 [분석하러 갈게요] + 아래 밑줄 링크 「바로 풀어 볼게요」
2. 도입: 글 내용 암시 → 칠판 풀이법 (「넘어가기」 링크)
3. 문장마다: **먼저 읽기**(첫 문장·처음 한 번만 이해 정도/아는 단어 슬라이더) → 질문 →
   맞으면 칭찬만 한 화면(자동 넘김) → 다음 질문 → 문장 끝 「○○을 아주 잘 이해했어요!」 → 「이제 ○○을 읽어 봐요」
4. 키워드 색칠한 보기 → 많이 고른 오답 「같이 볼까요?」 → 단어 체크 → 짝 맞추기 → 헷갈린 포인트

## 4. 문장 하나를 가르치는 도구 (확정된 것)

- **핵심어 찾기** (`pick`): 함정은 actually·altogether·we 같은 덧붙이는 말 (임시 — 너무 쉽다는 의견). *풀이 단어는 핵심어 아님
- **S·V·O 덩어리 찾기** (`pick` + `shade` + `roles`): 긴 문장은 읽기 직후. 맞히면 S/V/O 표시가 남는다. 예상 오답에 `wrong_by`
  (for + 명사 → "전치사가 붙으면 주어가 아니에요" → 뒤에 「~에게는」 설명)
- **자유 해석** (`translate`): 가이드 질문 뒤. 규칙 채점(need/wrong), 결과는 입력한 자리(아래)에, 틀리면 연습할 문장 저장.
  「잘 모르겠어요」는 밑줄 링크, 처음엔 "단어를 눌러 보고 써 봐요", 그래도 막히면 「답 바로 보기」
- **지시어** (this/that/such): "앞 문장에서 찾는다" → 앞 문장을 `flip`으로 띄우고 음영 구절 중 고르기
- **구조 설명** (while S+V, S+V): 슬래시로 나누기. 3등급 이하용 → `known` 키로 「이미 잘 알고 있어요」 건너뛰기
- **+/− 표시** (`signs`): 좋은 말/나쁜 말 판단 (빈칸·대조)
- **흐림** (`faded`): 콤마·대시 **두 개 사이**만. 대시 하나는 흐리지 않는다. 주어+동사 있는 메인 문장은 흐리지 않는다
- **칠판**: 단어 지도(`groups`, 끌어 넣기) · 그림(`picture`) · 지도(`map`)는 **칠판 서랍**(문장 자리를 덮는 큰 칠판, 오른쪽 손잡이로 여닫기).

## 6. 그림 틀 (아이디어 — 사용자에게 아직 확정 안 받음)

39번에서 사용자가 "집단 + 바깥의 외부인 → 집단 안의 지식에 닿지 못함" 그림 2장을 지시했다
(`public/assets/veil-group.svg`, `veil-knowledge.svg`). 사용자는 지문마다 그림을 직접 지시하지 않기를 원한다.
제안: 자주 나오는 장면을 **라벨만 바꿔 끼우는 그림 틀**로 만든다 —
집단 안/밖, A ↔ B 대조, 원인 → 결과, 예전 → 지금, 비유(장막·다리·렌즈). 규칙 예: "추상적 비유가 나오면 그림 2장: 상황 → 비유의 뜻".
