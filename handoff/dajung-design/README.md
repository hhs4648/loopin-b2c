# 다정쌤 디자인 전달 묶음

영어 해석 튜터 앱 **다정쌤**의 디자인과 화면 구성을 전달하는 묶음입니다.
코드와 교습 정책은 들어 있지 않습니다. 정책은 별도로 전달합니다.

실제로 돌아가는 모습: https://loopin-b2c.vercel.app
(애니메이션과 화면 전환은 직접 한 세트를 풀어 보는 게 가장 빠릅니다.)

## 들어 있는 것

| 경로 | 내용 |
|---|---|
| `DESIGN_HANDOFF.md` | **본문.** 디자인 원칙, 토큰, 화면 3개의 구성, 부품 규격, 화면이 받는 데이터 모양 |
| `screens/00-overview.png` | 전체 화면을 한 장에 모은 것 |
| `screens/01…18-*.png` | 상태별 실제 화면 |
| `assets/` | 캐릭터 그림 (png · webp · 원본 svg), 파비콘 |
| `reference/` | 현재 구현의 스타일시트와 교실 배경 코드, 토큰 JSON. 수치를 정확히 맞출 때만 봅니다 |

## GPT에 넣는 법

1. 새 대화에 `DESIGN_HANDOFF.md`와 `screens/00-overview.png`를 올립니다.
2. 아래 지시문을 붙여 넣습니다.
3. 특정 화면을 만들 때 그 화면의 스크린샷(예: `06`, `07`, `08`)을 추가로 올립니다.
4. 수치를 정확히 맞춰야 하면 `reference/styles.css`를 올립니다.

이미지를 한 번에 많이 올리면 뒤쪽이 무시되는 일이 있습니다. 개요 한 장으로 시작하고, 화면별로 나눠 올리세요.

### 붙여 넣을 지시문

```text
첨부한 DESIGN_HANDOFF.md는 「다정쌤」이라는 모바일 영어 해석 튜터 앱의 디자인 규격서이고,
이미지는 실제 화면입니다. 이 규격대로 화면을 구현해 주세요.

지켜야 할 것:
- 메신저형 채팅 로그를 만들지 않습니다. 선생님의 현재 한 마디와 학생의 마지막 한 마디만 보입니다.
- 말풍선은 캐릭터 위에 있고 꼬리는 아래를 향합니다.
- 화면은 셋입니다: 수업 목록 / 교실 대화 / 문장 학습. 각 화면의 주인공이 다릅니다 (규격서 1장).
- 색, 글꼴, 모서리, 그림자, 애니메이션은 규격서 2장의 값을 그대로 씁니다.
- 화면 컴포넌트는 규격서 8장의 TutorView 값을 받아서 그리기만 합니다.
  수업 진행 판단(채점, 힌트, 다음 문장으로 넘어가기)을 화면 코드에 넣지 않습니다.
- 교습 정책은 이 문서에 없습니다. 추측해서 만들지 말고, 가짜 TutorView 데이터로 화면만 먼저 완성합니다.
- 규격서 11장에 적힌 기존 구현의 문제는 고쳐서 만듭니다.

먼저 (1) 디자인 토큰 파일, (2) 공용 부품, (3) 화면 세 개 순서로 진행하고,
각 단계에서 스크린샷의 어느 상태를 재현했는지 알려 주세요.
기술 스택: <여기에 사용할 스택을 적으세요>
```
