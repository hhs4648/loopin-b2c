# 다정쌤 — 디자인 · 화면 구성 규격서

> 이 문서는 **디자인과 화면 구성만** 다룬다.
> 교습 정책(언제 힌트를 주는지, 어떻게 채점하는지, 모델에게 무엇을 시키는지)은 **여기 없다.** 그건 별도 문서로 새로 정해져 있으므로, 이 문서에서 정책을 추측해 만들지 말 것.
> 이 문서만 읽고도 같은 화면을 다시 만들 수 있게 썼다. 프레임워크·언어는 자유다.

## 1. 무엇을 만드는가

**다정쌤**은 학생이 영어 문장을 한국어로 해석하면 선생님 캐릭터가 한 턴씩 받아 주는 1:1 수업 앱이다. 모바일 세로 화면 하나로 돈다.

### 디자인 원칙 — 색보다 이게 먼저다

1. **메신저가 아니다.** 대화 로그를 쌓지 않는다. 화면에는 **선생님의 현재 한 마디**와 **학생의 마지막 한 마디**만 있다. 새 말이 오면 이전 말은 사라진다. 스크롤되는 채팅 목록을 만들지 말 것.
2. **말풍선은 캐릭터 위에 있다.** 꼬리는 아래(캐릭터 쪽)를 향한다. 캐릭터가 말하는 것처럼 보여야 한다.
3. **화면마다 주인공이 다르다.**
   - 수업 목록 → **카드**가 주인공. 선생님은 오른쪽 아래 구석 장식.
   - 교실 대화 → **선생님**이 주인공. 가운데 크게 서 있다.
   - 문장 학습 → **영어 문장**이 주인공. 선생님은 작아져 아래로 내려간다.
4. **빠른 대답은 알약 버튼.** 핑크 테두리, 오른쪽 정렬, 입력칸 바로 위. 선생님이 "입력 중"일 때는 숨긴다.
5. **설명할 것을 말로 하지 않고 보여 준다.** 해석하지 않아도 되는 이름(회사명·인명)은 선생님 대사에 넣지 않고 **칩**으로 띄운다. 단어 뜻은 문장 속 단어를 **눌렀을 때만** 뜬다.
6. **따뜻하고 부드럽게.** 크림색 교실, 핑크 포인트, 큰 radius, 갈색 기운의 부드러운 그림자. 직각·순수한 검정·차가운 회색을 쓰지 않는다.

### 움직임

```css
@keyframes bob   { 0%,100% { transform: translateY(0) }  50% { transform: translateY(-6px) } }
@keyframes pop   { 0% { opacity:0; transform: translateY(10px) scale(.96) }  100% { opacity:1; transform:none } }
@keyframes dot   { 0%,80%,100% { opacity:.25 }  40% { opacity:1 } }
@keyframes blink { 0%,100% { opacity:1 }  50% { opacity:.3 } }
@keyframes lit   {
  0%,100% { box-shadow: 0 12px 30px rgba(60,30,20,.16), 0 0 0 1px rgba(226,96,125,.18) }
  35%     { box-shadow: 0 12px 30px rgba(239,122,147,.34), 0 0 0 3px rgba(239,122,147,.5) }
}
```

| 애니메이션 | 어디에 | 시간 |
|---|---|---|
| `bob` | 캐릭터가 천천히 위아래로 | 3.4s ease-in-out 무한 |
| `pop` | 말풍선·알약 줄·문장 학습 화면이 나타날 때 | 0.3~0.4s ease-out |
| `dot` | 입력 중 점 3개 (0 / 0.2 / 0.4s 지연) | 1.2s 무한 |
| `blink` | 타이머의 빨간 점 | 1.6s 무한 |
| `lit` | **학생이 스스로 답을 고친 순간**에만 말풍선 테두리가 한 번 핑크로 밝아졌다 가라앉음 | 1.3s ease-out, 0.1s 지연 |

`lit`은 칭찬 연출이다. 아무 때나 켜지 않는다 — 켤지 말지는 화면이 아니라 수업 로직이 정해서 `effect: "light"`로 내려 준다 (`screens/09`).

## 3. 틀 — 휴대폰 액자

- 기준 캔버스는 **390 × 844**.
- **폭 640px 이하(휴대폰)**: 액자를 버리고 화면을 꽉 채운다 (`width: min(100%, 480px); height: 100%`).
- **그보다 넓으면(데스크톱)**: `#1d1a1f` 배경 한가운데에 390×844 액자를 놓는다. 창이 작으면 통째로 축소한다 (`scale(min(100vw/390px, 100vh/844px, 1))`). 확대는 하지 않는다 (`screens/18`).
- 액자 안쪽의 크기는 **컨테이너 쿼리 단위**(`cqw`, `cqh`)로 잡는다. 액자에 `container-type: size`를 걸면 안의 모든 것이 액자 크기를 따라온다. 뷰포트 단위(`vw`)를 쓰면 데스크톱 액자 안에서 깨진다.
- `html, body { overflow: hidden; overscroll-behavior: none }` — 페이지 자체는 절대 스크롤되지 않는다. 스크롤은 목록·지문·말풍선 **안쪽**에서만.
- 위아래 여백에 `env(safe-area-inset-top/bottom)`을 더한다.
- **카카오톡 같은 인앱 브라우저**는 `100dvh`를 위아래 막대 포함으로 잰다. 그러면 화면이 잘린다. `window.innerHeight`를 직접 재서 CSS 변수(`--app-h`)로 넘기고 높이를 그걸로 잡는다. `visualViewport.height`는 쓰지 말 것 — 키보드가 올라올 때마다 화면이 쪼그라든다.

## 4. 화면 셋

```
[화면 0 수업 목록] ──세트 선택──▶ [화면 1 교실 대화] ──준비됐어요──▶ [화면 2 문장 학습]
        ▲                              ▲    │                            │
        │                              │    └── ← 버튼으로 잠깐 돌아옴 ◀──┘
        └────── X(학습 종료) · 「수업 목록으로」 ◀── 마지막 문장 뒤 교실로 돌아와 끝 ──┘
```

### 화면 0 — 수업 목록 (`screens/01`, `02`, `17`)

두 단계다. 처음엔 **묶음**(예: 「2024 수능」)이 보이고, 하나를 누르면 그 안의 **문제 카드**들이 나온다.

```
┌──────────────────────────────┐
│ (다) 다정쌤                   │ ← 상단 칩. 2단계에서는 ← 버튼으로 바뀜
│      영어 해석 수업           │
│                              │
│ 오늘은 어떤 걸 볼까요?        │ ← Gowun Dodum 14px muted
│ 수업 목록                    │ ← 26px / 800
│                              │
│ 수능  대학수학능력시험 기출   │ ← 대분류는 카드가 아니라 제목
│ ┌──────────────────────────┐ │
│ │ [기출]                    │ │ ← 태그 (2단계 카드에는 없음)
│ │ 2024 수능                 │ │
│ │ 2024학년도 …              │ │
│ │ (26문제 · 226문장)  열기 › │ │
│ └──────────────────────────┘ │
│ …                       🧸   │ ← 캐릭터: 오른쪽 아래, 카드 뒤(z 낮음)
└──────────────────────────────┘
```

- 배경은 교실 그대로. 단 **시계와 화분은 숨긴다** (캐릭터 자리와 겹친다).
- 캐릭터: `right: 2cqw; bottom: 5%; width: min(46cqw, 22cqh)`, 클릭 안 됨, 말풍선 없음.
- 목록 영역: 상단 78px 아래부터 끝까지, 좌우 18px, 세로 스크롤.
- 카드: 흰색 92% + blur, radius 22, padding `16px 18px 14px`, 카드 사이 12px.
  - 아래 줄 왼쪽: 분량 배지 (`n문장`, 12px/600, `#f4efe9` 알약)
  - 아래 줄 오른쪽: `시작하기 ›` (13px/700, accent-deep)
- **끝낸 문제**: 목록 맨 아래로 내려가고, 배경 70% 투명·글씨 muted, 제목 옆 초록 「완료」 배지, 버튼 글씨는 「다시 풀기」.
- 인사말에 학생 이름을 넣는다: 「지우님, 오늘은 어떤 걸 볼까요?」 / 칩 아랫줄 「지우님과 함께」.

### 화면 1 — 교실 대화 (`screens/03`, `04`, `05`, `11`, `16`)

수업의 시작(이름 묻기 → 오늘 볼 것 소개)과 끝(마무리 인사)에 쓴다.

```
┌──────────────────────────────┐
│ (다) 다정쌤      ● 00:02  (X) │ ← 칩 / 타이머 / 닫기
│      18번 문제                │ ← 칩 아랫줄 = 지금 푸는 세트 이름
│  ┌────────────────────────┐  │
│  │ 화이트보드       ● ● ●  │  │ ← 비어 있음. 장식
│  └────────────────────────┘  │
│  ╭──────────────────────╮    │
│  │ 안녕하세요, 지우님! … │ 🕐 │ ← 선생님 말풍선 (가운데)
│  ╰──────────◆───────────╯    │ ← 꼬리: 아래 가운데
│           🧸            🪴   │ ← 캐릭터 가운데, bob
│                     ╭─────╮  │
│                     │ 지우 │  │ ← 학생 마지막 말 (오른쪽, 핑크)
│                     ╰─────╯  │
│        그대로 쓰면 되는 이름이에요 │ ← 이름 칩 안내 (있을 때만)
│           [Lewis Ltd. · 회사 이름]│
│       (네, 좋아요!) (잘 모르겠어요)│ ← 알약 버튼, 오른쪽 정렬
│ ╭──────────────────────────╮ │
│ │ 선생님께 답해 보세요…  🎤 ↑│ │ ← 입력칸
│ ╰──────────────────────────╯ │
└──────────────────────────────┘
```

| 요소 | 위치 · 크기 |
|---|---|
| 상단 바 | `top: 0`, padding `14px 16px 0` (+safe-area). 양 끝 정렬 |
| 캐릭터 | 가로 가운데, `bottom: max(15%, 118px)`, 폭 `min(58cqw, 27cqh)` (390×844에서 약 226px) |
| 선생님 말풍선 | 가로 가운데, **캐릭터 머리 바로 위** (`bottom: max(17%,132px) + 캐릭터 폭`). `max-width: 86cqw`, `min-width: min(200px, 56cqw)`, 가운데 정렬 글씨. 길어지면 위로 자라지 않고 **말풍선 안에서 스크롤** |
| 말풍선 꼬리 | 22×22 흰 사각형을 45° 돌려 아래 가운데에 (`bottom: -11px`, radius 4) |
| 학생 말풍선 | `right: 16px`, `bottom: max(17%,132px) + 26px`, `max-width: 62cqw`. 이름 칩이 떠 있으면 72px 더 올린다 |
| 하단 도크 | `bottom: 0`, padding `0 14px 16px` (+safe-area), 세로로 쌓음(간격 10px): 이름 칩 → 알약 줄 → 입력칸 |

상태:

- **입력 중**: 말풍선 안 글씨 대신 핑크 점 3개. 알약 버튼은 숨기고 입력칸은 비활성 (`screens/05`).
- **이름 묻기**: 버튼 없음, placeholder 「이름을 알려 주세요…」 (`screens/03`).
- **끝**: 입력칸 대신 알약 버튼 「수업 목록으로」 하나만 오른쪽에 (`screens/16`).

### 화면 2 — 문장 학습 (`screens/06`~`10`, `12`~`15`)

수업 시간 대부분을 여기서 보낸다. 선생님이 설명하거나 되물을 때도 **이 화면을 떠나지 않는다** — 학생이 영어 문장을 보면서 답해야 하기 때문이다.

```
┌──────────────────────────────┐
│ (←)   문장 학습 · 3 / 7   (X) │
│        ▬ ▬ ▬ · · · ·         │ ← 진행 점
│                              │
│ However, after careful       │ ← 영어 문장. 크게. 왼쪽 정렬
│ consideration, I have …      │    단어마다 핑크 점선 밑줄

│  ╰──────────◆───────────╯    │
│              🧸              │ ← 작은 캐릭터
│ (다 읽었어요)(힌트 주세요)(잘 모르겠어요)
```

세로로 네 칸을 쌓는 flex 레이아웃이다. 배경은 교실 그림 없이 `#f7efe6` 단색.

| 칸 | 규칙 |
|---|---|
| ① 상단 바 | 고정 높이. ← (40px 흰 원) / 진행 표시 / X (36px 짙은 원) |
| ② 지문 | padding `18px 24px 8px`. **높이는 화면의 34%까지만**, 넘으면 이 칸 안에서 스크롤. 화면이 낮으면 이 칸이 먼저 줄어든다 |
| ③ 무대 | 남는 높이 전부 (`flex: 1`, 최소 132px). 캐릭터는 아래 가운데, 말풍선은 그 머리 위. 캐릭터 폭 `min(42cqw, 52cqh, 100cqh - 116px)` — **화면이 낮으면 캐릭터가 먼저 작아지고 말풍선 자리를 남긴다** |
| ④ 도크 | 고정. 알약 줄 + 입력칸 (간격 12px) |

세부:

- **진행 점**: 문장 수만큼. 꺼진 점 8×5px `#e6d8cc`, 켜진 점 18×5px accent. 간격 5px, radius 3. 위에 `문장 학습 · 3 / 7` (12px/600 muted, 자간 .04em).
- **영어 단어**: 단어(또는 구) 하나하나가 버튼이다. 핑크 50% 점선 밑줄(`underline dotted`, offset 5px). 누르면 배경이 `rgba(239,122,147,.16)`으로 물들고 **바로 아래에 툴팁**이 뜬다. 다시 누르거나 바깥을 누르면 닫힌다 (`screens/07`).
  - 툴팁: 흰 배경, 1.5px `#f0d3db` 테두리, radius 12, padding `7px 11px`, 위쪽에 6px 삼각 꼬리, `max-width: min(240px, 62cqw)`.
  - 여러 단어로 된 구(`the past four years`)는 **통째로 하나**로 누른다.
- **이름(고유명사)**: 문장 안에서는 아래쪽 45%만 핑크 35%로 칠한 형광펜. 문장 아래에 칩 `Lewis Ltd. · 회사 이름 · 그대로` (높이 28, 12px/600, 흰 배경, `#f0d3db` 테두리). 그 문장에 이름이 있을 때만 뜬다 (`screens/13`).
- **듣기**: 흰 알약(높이 40, accent-deep 글씨, 스피커 아이콘). 브라우저 TTS로 문장을 영어로 읽는다. 옆에 안내문 `단어를 누르면 뜻이 나와요 · 18 words` (넘치면 말줄임).
- **알약 버튼은 상황마다 바뀐다.** 기본은 `다 읽었어요 / 힌트 주세요 / 잘 모르겠어요`. 선생님이 둘 중 하나를 고르게 할 때는 그 보기 둘이 버튼으로 뜬다 (`screens/08`, `15`). 버튼 목록은 화면이 정하지 않고 받아서 그린다.
- 이 화면에는 **학생 말풍선이 없다.** 학생이 방금 쓴 말은 ←로 교실에 돌아갔을 때만 보인다 (`screens/11`).
- ← 는 교실 대화로 잠깐 돌아간다 (다음 답을 보내면 다시 이 화면). X 는 수업을 끝내고 목록으로.

## 7. 캐릭터

- 이름은 **다정쌤**. 분홍색 말랑한 몸, 갈색 긴 웨이브 머리, 보라색 책을 안고 한 손을 흔든다. 주변에 작은 하트 둘.
- 그림 하나로 모든 화면을 쓴다 (`assets/dajung-teacher.png`, 650×616, 거의 정사각). 표정·포즈 변화는 아직 없다.
- 크기는 **부모 폭으로만** 정한다 (`width: 100%; height: auto`). 그림이 정사각에 가까워서 폭이 곧 키다 — 폭을 키우면 머리가 말풍선 뒤로 들어가니, 말풍선 위치와 캐릭터 폭은 **같은 변수**를 봐야 한다.
- 항상 `bob`으로 천천히 떠 있고 아래에 부드러운 그림자.

## 8. 화면은 받은 것만 그린다

화면 쪽에는 수업 판단이 없다. 매 턴 아래 모양의 값 하나를 받아서 그대로 그린다. 새로 만들 때도 이 경계를 지키면 정책을 어떻게 바꾸든 화면은 안 건드려도 된다.

```ts
type TutorView = {
  screen: "chat" | "study";     // 어느 화면인가
  message: string;              // 선생님 말풍선
  buttons: string[];            // 알약 버튼. 비면 자유 입력만
  placeholder: string;          // 입력칸 안내문
  studentLine: string;          // 학생 마지막 말 (교실 화면에서만 표시)
  effect: null | "light";       // "light"면 말풍선 lit 애니메이션
  sentence: string;             // 지금 영어 문장
  progressIndex: number;        // 3
  progressTotal: number;        // 7
  properNouns: { en: string; ko: string; type?: string }[];  // 이름 칩
  glosses: { en: string; ko: string }[];                     // 눌렀을 때 뜰 단어 뜻
  ended: boolean;               // true면 입력칸 대신 「수업 목록으로」
};
```

턴 하나의 화면 흐름:

1. 학생이 입력칸에 쓰고 보내거나 알약 버튼을 누른다 (버튼은 그 글자를 그대로 보낸 것과 같다).
2. 곧바로 **입력 중** 상태: 말풍선에 점 3개, 버튼 숨김, 입력칸 비활성. 최소 0.7초는 보여 준다 (응답이 즉시 와도 선생님이 생각하는 틈을 둔다).
3. 새 `TutorView`가 오면 말풍선이 `pop`으로 바뀌고 버튼이 다시 뜬다. `screen`이 바뀌었으면 화면을 전환한다.

## 9. 화면에 박혀 있는 글자

수업 내용이 아니라 **UI가 가진 글자**만 적는다.

| 자리 | 글자 |
|---|---|
| 상단 칩 | 다정쌤 / 영어 해석 수업 · {이름}님과 함께 · {세트 이름} |
| 목록 인사 | 오늘은 어떤 걸 볼까요? · {이름}님, 오늘은 어떤 걸 볼까요? |
| 목록 제목 | 수업 목록 |
| 카드 | 열기 · 시작하기 · 다시 풀기 · 완료 · n문제 · n문장 · n문제 중 n 완료 |
| 입력칸 | 이름을 알려 주세요… · 선생님께 답해 보세요… · 해석을 적어 보세요… |
| 기본 버튼 | 네, 좋아요! · 잘 모르겠어요 · 다 읽었어요 · 힌트 주세요 · 더 알고 싶어요 · 다음으로 |
| 문장 학습 | 문장 학습 · n / N · 듣기 · 단어를 누르면 뜻이 나와요 · n words |
| 이름 칩 | 그대로 쓰면 되는 이름이에요 / {이름} · {종류} / {이름} · {종류} · 그대로 |
| 끝 | 수업 목록으로 |
| 툴팁(title) | 학습 종료 · 이전 · 목록으로 · 보내기 · 음성으로 말하기 |

말투는 전부 **해요체**다. 반말과 딱딱한 합쇼체를 쓰지 않는다.

## 11. 지금 구현의 거친 곳 — 그대로 베끼지 말 것

새로 만들 때 고쳐서 가져가면 좋은 자리들이다.

- **문장 학습 화면의 캐릭터가 가운데에서 오른쪽으로 밀려 있다** (`screens/06` 등). 의도는 가운데 정렬이다. 가운데 정렬용 `transform: translateX(-50%)`와 `bob` 애니메이션의 `transform`이 같은 요소에서 부딪혀서 생긴 일이다. 교실 화면처럼 **정렬용 껍데기와 애니메이션용 안쪽 요소를 나누면** 된다. 말풍선 꼬리가 캐릭터 머리를 가리키게 맞출 것.
- **목록 1단계에서 글자가 화이트보드 위에 겹친다** (`screens/01`). 목록 화면에서는 화이트보드를 흐리게 하거나 숨기는 편이 낫다.
- **학생 말풍선이 길면 캐릭터를 가린다** (`screens/16`).
- 마이크 버튼은 모양만 있고 동작하지 않는다.
- `[기록] …` 한 줄이 끝 화면 맨 아래에 작게 보인다 (`screens/16`). 개발용 표시이고 학생에게 보일 것이 아니다.
- 캐릭터 표정이 하나뿐이다. 칭찬·생각 중 표정이 생기면 `lit` 효과, 입력 중 점과 짝지을 수 있다.
