# 문제 넘기기

**지문만 주시면 됩니다.** 문장 나누기·해석·채점 포인트·오해·단어 뜻·유도 문구는
전부 만들어서, 고칠 데만 보시게 표로 돌려드립니다.

## 세 단계

1. **주기** — `SUBMIT.md`를 채워서 이 폴더에 두거나 대화창에 붙여 주세요.
   세트 제목·유형·출처 + 지문. 그게 답니다
2. **검토** — 제가 `REVIEW-<세트>.csv`를 만들어 드립니다. 문장별로 제가 나눈 문장,
   제가 쓴 해석, 제가 고른 채점 포인트, 제가 추측한 오해가 들어 있습니다.
   **「고칠 것」 칸에만** 적어 주세요. 비워 두면 그대로 갑니다 (`REVIEW-EXAMPLE.csv` 참고)
3. **반영** — 고쳐서 레슨 JSON으로 바꾸고 수업 목록에 올립니다

## 제가 못 하는 것 하나

**「자주 하는 오해」는 추측입니다.**

지문만 보고도 잡히는 건 있습니다 — `invaluable`의 `in-` 접두사, `serve`처럼 뜻이
갈리는 말, 분사구문 어순 같은 것. 하지만 *우리 애들이 유독 여기서 걸린다*는 건
교실에서만 나옵니다. 그게 좌절 방지의 2지선다와 오답 대사를 만드는 재료라
검토표에서 이 칸을 제일 눈여겨봐 주세요.

아는 오해가 있으면 `SUBMIT.md`에 미리 적어 주셔도 됩니다. 그러면 그걸 쓰고,
제 추측은 보태기만 합니다.

## 알아 두실 것

- **채점 포인트 순서가 곧 수업 순서**입니다. 못 낸 것 중 첫 번째부터 짚습니다.
  한 문장에 2~3개가 적당하고, 다섯 개가 넘으면 그 문장을 둘로 끊는 게 낫습니다
- 문장이 길면 한 문장을 둘로 끊을 수 있습니다. 끊었으면 검토표에 그렇게 나옵니다
- **저작권** — 수능·모의고사 기출은 출처를 적고 그대로 씁니다. 교과서 지문이면
  그대로 옮기지 않고 같은 유형으로 새로 씁니다. 출처 칸에 어느 쪽인지 남겨 주세요
- 오해가 하나도 없는 문장은 좌절 방지에서 2지선다 없이 설명만 하고 넘어갑니다
