# 테스트 시나리오

프롬프트나 상태머신을 바꿀 때마다 아래 학생 역할로 한 바퀴 돕니다. 원안 체크리스트 + 구현 시 깨지기 쉬운 분기를 포함합니다.

레슨: `content/tutor/lessons/thales-participial-phrase-front.json`

## 자동화된 것

```bash
npm test          # 한 번 돌리기 (`npm run build`에도 들어 있다)
npm run test:watch
```

| 파일 | 무엇 |
|------|------|
| `src/tutor/engine.test.ts` | 진단·체크리스트 유도·좌절 방지·기록 네 값·항목 기록·한 턴 질문 하나·LLM 자리 |
| `src/tutor/lesson-content.test.ts` | 레슨 글 자체 (힌트가 정답을 흘리는지, 반말, 질문 두 개, 데이터 계약) |
| `src/tutor/llm.test.ts` | 가드레일 |

아래 표의 **#1 · #3 · #4 · #11 · #12 · #13 · #14는 자동으로 돕니다.** 나머지는
모델이 있어야 하거나(다중 라운드) 아직 엔진에 없는 기능이라 사람이 봅니다.

`#11 역질문`은 셋으로 갈립니다.

| 물어본 것 | 다정쌤 | miss |
|---|---|---|
| 고유명사 (`Lewis Ltd.`) | 그대로 쓰면 된다 + 복귀 | 안 셈 |
| **이번 문장이 가르치는 단어** (`serve`) | 그 항목의 유도 한 번 — 콕 집은 응답이지 뜻을 주지는 않는다 | 셈 |
| 그 외 단어 (`company`) | 뜻을 알려 주고 복귀 (모델이 답한다) | 안 셈 |

가르치는 단어의 뜻은 **곧 그 문장의 정답**입니다. 그냥 알려 주면 학생은 다음부터 해석
대신 단어부터 물어보고, 유도에 옆문이 생깁니다. 그래서 코드가 사다리로 답합니다.
그 외 단어는 레슨 JSON에 사전이 없어 모델이 답하고, 어댑터가 없으면 항목 유도로 폴백합니다.

## 필수 5개 (원안)

| # | 학생 역할 | 통과 조건 |
|---|-----------|-----------|
| 1 | “밀레투스가 소아시아에서 태어났다” | **E2** 처치 (주어 오인). E1이 같이 보여도 **E2를 먼저**. 한 턴에 둘 다 설명하면 실패 |
| 2 | “소아시아의 밀레투스에서 태어났다” | **E1** — “Born이 동사일까요, 과거분사일까요?” 고정 질문. 정답 해석을 바로 주면 실패 |
| 3 | “잘 모르겠어요” 3연속 | 못 한 항목 유도 → 같은 항목 재실패 시 그 항목만 `tell`. 모범 해석 전체는 좌절 방지에서만 |
| 4 | 청크1 모범 해석을 바로 말함 | 구체적 칭찬(born/in 등) 후 **청크2**로. 전체 강의하면 실패 |
| 5 | 청크2에서 “모르겠어요” | `teach_points`를 **한꺼번에 쏟지 않음**. 주어/동사만 다루고 기다림 |

## 실패로 보는 공통 증상

- 해요체가 깨지거나 반말
- 한 턴에 질문/설명이 두 개 이상
- 학생이 치기 전에 모범 해석을 말함
- 말버릇(^^, 어머)을 매 문장에 붙임
- 레슨에 없는 문법 강의
- `[기록]`을 학생 말투로 읽게 함
