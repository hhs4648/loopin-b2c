# 유형별 수업 틀

모의고사 한 문제를 레슨으로 만들 때 따르는 틀. **공통 틀**(모든 유형) 위에 **유형 틀**(빈칸·순서·문장 넣기…)을 얹는다.
새 문제는 유형 틀의 체크리스트대로 생성기(`scripts/lessons/gen_*.py`)를 쓰고, 테스트(`npm run build`)가 규칙을 검사한다.

- 공통 틀: 이 문서
- 유형 틀: [빈칸](blank.md) · [순서](order.md) · [문장 넣기](insertion.md) · [밑줄 의미](underline.md) · [제목·주제·요지](title.md) ·
  [어휘](vocab.md) · [어법](grammar.md) · [요약문](summary.md)(초안, 선생님 검토 전) · 듣기 응답(초안, 아래 §4)
- **2026-10-20~21에 바뀐 공통 규칙은 바로 아래 §0-1** — 아래 본문과 다르면 §0-1이 맞다
- 말투·화면 규칙의 근거: `docs/tutor/policy/AUTHORING_RULES.md`, 말투 `content/tutor/policy-copy/dajung/VOICE.md`

이 틀은 **모의고사·수능** 갈래(`sets.json` 대분류 `track: "exam"`)용이다. 나중에 만들 일반 영어는 플로우가 달라 따로 관리한다.

## 0. 시험 이름 표기 (모의고사·수능 공통)

- 제목은 모두 **시행연도**(2026-10-21 선생님). 예: 2026년 6월 시행 → 「2026년 6월 모의평가」, 2025년 11월 → 「2025년 11월 수능」
- 평가원(6월·9월 모의평가, 수능)은 흔히 **학년도**(시행연도 +1)로 부르니 부제 맨 앞에: 「2027학년도 6월 모의평가 · 한국교육과정평가원」
- 목록은 시행한 해로 묶고(해 제목), 위에 안내 한 줄 — 교육청(3·4·5·7·10월)은 원래 시행연도
- `sets.json` 중분류에 `exam: { body: "평가원" | "교육청", held: "YYYY-MM" }` — 테스트(`src/tutor/sets.test.ts`)가 제목 연도와 부제를 검사한다 (2026-10-14 선생님)

## 1. 수업 한 판의 모양 (공통)

```
지문 한눈에 보기 ─┬─ [분석하러 갈게요] ─ 도입 ─ (유형별: 읽기 전에 짚기) ─ 문장마다 ↓ ─ (유형별 마무리) ─ 문제 풀기 ─ 단어 체크 ─ 헷갈린 포인트
                  └─ 「바로 풀어 볼게요」 ─ 맞히면 [제대로 분석]/[핵심 정리]/[끝내기], 틀리면 분석으로
```

**도입** — 주제 한 줄(매번) + 풀이법 설명(그 유형을 **처음** 풀 때만, `method…` id).
도입 주제 화면엔 **칠판 그림**(`images.topic`, `public/assets/topic-*.svg`)으로 글 내용을 간단히 — 그림이 가장 좋고, 안 되면 간단한 표·구도.
칠판 글자는 **영어(괄호 한국어)**: Geography (지리학) — Where (어디). 아래 한 줄 물음으로 글을 암시(답은 말하지 않는다) (2026-10-14 선생님)

**문장마다** — 유형 틀이 정한 **열쇠 문장**은 아래를 다 하고, 나머지 문장은 읽기 + 한 줄 정리만 (빈칸: 재진술 문장이 열쇠)

1. **먼저 읽기** — 영어 문장만. 「다 읽었어요」는 1.2~3.5초 뒤에 뜬다
2. **주어·동사 찾기** — 회색 음영 덩어리를 눌러서(`pick` + `shade` + `roles`). 있으면 함께:
   목적어(O), 보어(C), **동사에 딸린** 전치사의 목적어(전목: learn **from experts**, associated **with geography**).
   꾸미는 전치사구 안의 명사(with tests, of skills)는 찾게 하지 않는다. 찾은 건 S·V·O·C·전목 표시로 남는다
   **that(명사절) 안이 핵심이면 메인 주어·동사 다음 그 안의 주어·동사(+O/C)도 찾는다** — 조건 두 가지: ① 접속사가 이끄는 완전한 절(명사절·동격절·in that·if/whether)
   ② 그 안의 내용이 핵심. 예: (C) The problem is that we can always respond… / the idea that a musical act is a thing / the premise that it matters where …
   도구 `add_that_sv(sentences, 문장 id, 메인 찾기 id, …)` (2026-10-16 선생님, 공통)
   **5형식(S V O C — enable/allow/make/help O to-V·형용사 등)은 보어(C)까지 다 찾는다** — SVO에서 멈추면 「목적어가 무엇을 하게/어떻게 되는지」가 빠진다.
   to부정사·분사 보어도 덩어리째 C로 표시 (2026-10-16 선생님, 3월 38번 enables speakers to conceptualize)
   중·초에게는 찾은 다음 화면에 읽는 법 한 줄(문법 용어 없이): 「enables + 사람 + to ~는 『사람이 ~하게 해 준다』로 읽어요」 + 💡 「동사 + 사람 + to ~」
   **끊어읽기:** 긴 문장에는 문장 데이터에 `slashes`(이 말 뒤에 /)를 적는다 — 화면의 「/ 끊어읽기」를 누르면 의미 덩어리마다 / 가 보인다.
   끊어읽기를 모르는 학생용 보조 도구 (2026-10-16 선생님, 3월 36번에 먼저)
   **긴 문장(20단어~)은 고·중·초 모두 주어·동사를 다 찾는다**(초급 「맞추기 ↔ 주어·동사」 번갈아 내기에서 뺀다).
   **주어·동사를 꾸며 주는 덩어리**(관계사 생략 the gestures (that) hearing people produce …, 분사구, 관계절)가 있으면
   찾기 다음 화면에 **꾸밈 구조 표**를 보인다 — S / ↖ 꾸밈 / V 세 줄, 문장에서 S는 노랑·꾸밈 덩어리는 초록(`highlight_alt`),
   말은 한 줄(「초록 부분은 앞의 ○○를 꾸며요. 아래 표처럼 읽어요.」). 꾸밈 안의 주어·동사를 누르면 「꾸미는 덩어리 안의 ~예요」 (2026-10-16 선생님, 3월 38번)
3. **그 문장의 열쇠 한두 개** — 문장에 따라 고른다
   - 가리키는 말(One word, this task, the iteration) → 문장에서 찾아 누르기
   - 헷갈리는 뜻(appreciation, present, bear, scale) → 3지 객관식, 그다음 설명
   - 구조(not simply A; B, there are, Nor, 대시 앞뒤, but 뒤) → 짧은 설명 + Tip
   - **평소와 반대로 평가하는 핵심어** → 꼭 짚는다(공통 규칙). 보통은 나쁘게 보는 말(대화를 멈추게 함, 망각, 실패 …)을
     글쓴이가 좋게 보거나, 보통 좋은 말을 나쁘게 볼 때 — 「글쓴이는 좋게 볼까요, 나쁘게 볼까요?」 2지 →
     근거가 된 평가어(benefit, value, useful / problem, cost …)를 칠하고 +/− 표시를 남긴다 (2026-10-15 선생님, 36번 conversation-stoppers).
     **두 조건이 다 맞을 때만:** ① 글의 **핵심어**일 것(예시 속 지나가는 말 X) ② 글쓴이 입장이 **한쪽으로 확고**할 것.
     30번처럼 글쓴이가 중립(이름 붙이기·구체적 특징이 각자 장단점)이면 적용하지 않는다
     **평가는 주장 맥락으로 읽는다** — 단어의 평소 느낌이나 문장 안의 칭찬어(served us well)로 정하지 않는다. 다만 설명은 **가볍게**:
     36번은 「대화를 멈추는 게 좋을 때도 있다」는 앞 맥락으로 둘째 문장을 읽고, 「늘 이유를 따지는 건 많은 상황에서 도움이 되지만
     멈춤과는 약간 반대 — 때로는 멈출 수 있는 게 좋을 수도 있다」 정도만. 관계 질문·+/− 세부 분석·「꼭 표시해 둬요」 같은 요령 말은 과부하라 뺀다 (2026-10-15 선생님)
   - 문장 뜻 → 3지 객관식 또는 **핵심어 요약**(노란 핵심어만 보고 직역 말고 상황을 한 줄로)
     또는 **해석 맞추기**(짧은 문장만 — 영어 덩어리를 끌어 한국어 해석 칸에. 문장 전체가 아니어도 S·V·O/C + 핵심어만으로).
     해석 맞추기는 **중·초는 짧은 문장이면 모두** 같은 자리의 다른 방식과 돌려 낸다. 고는 미정 (2026-10-14 선생님)
   - **방식 돌려 내기(듀오링고처럼):** 같은 방식만 계속 나오면 질린다. 뜻을 확인하는 자리에 방식을 두세 개 적고
     같은 `slot`을 달면, 학생 단계에 맞는 것 중 **최근에 덜 한 방식**이 하나만 나온다(학생 기기에 최근 6개 기억) (2026-10-14 선생님)
   - **해석 맞추기를 하는 문장은** 주어·동사(+O/C/전목) 찾기, 뜻을 다시 풀어 말하는 화면, 뜻 객관식을 **건너뛴다** —
     맞추기가 이미 그 일을 한다. 뜻 다시 풀기·뜻 확인 화면엔 `meaning_check: True`를 단다 (2026-10-14 선생님)
4. **그림·단어 지도**(필요할 때) — 칠판 서랍으로 크게. 단어 지도는 첫 단어만 넣고 나머지는 학생이 끌어 넣는다.
   **칠판에는 지금까지 읽은 문장에서 알 수 있는 것만** 쓴다 — 뒤 문장 내용, 정답 보기와 같은 말을
   묶음 이름·아래 한 줄로 미리 쓰지 않는다 (2026-10-14 선생님, 공통 규칙).
   이미 분류한 단어는 다시 분류하지 않는다

**그림 칠판 아래 단어 칩은 그림 속 글자와 겹치면 넣지 않는다** — 그림에 이미 영어 핵심어가 적혀 있으면 아래 칩(`words`)은 중복이다 (2026-10-19 선생님).

**대사 세 번이면 칠판** — 한 지문에서 설명·뜻 질문 대사가 **세 번 이상 이어지면**(주어·동사 찾기·짝 맞추기 같은 고르기는 덜 지루해서 세지 않는다) 칠판(핵심어 + 그림 이모지)으로 정리한다. 말로 더 늘어놓지 않고 칠판에 한 줄씩 쌓는다(읽은 데까지만). 예: 3월 36번 주어진 글 — 역할 질문·평가 질문 뒤 세 번째 설명을 칠판으로(⚖️ moral considerations / 🛑 = conversation-stoppers / 👍 one benefit · their value) (2026-10-16 선생님).

**칠판 정리** — **2~3문장마다 고정으로** 「지금까지 어떤 상황인지」 칠판에(`panel.kind = "story"`). 장면 한 줄 = 그림(이모지) +
영어 핵심어 + 한국어 한 줄, 장면이 쌓이고 이번에 붙은 것만 노랗게. 장면은 `scripts/lessons/story_boards.py`의 `STORIES`에 쓰고
생성기가 `add_story_boards`로 끼운다. **답을 말하지 않는다** — 밑줄 의미·제목처럼 요약이 곧 답이면 마지막 문장 앞에서 멈추고,
빈칸은 ____로, 문장 넣기는 내용만 (2026-10-14 선생님). **순서 문제는 넣지 않는다** — 시험지 순서라 이야기가 안 맞는다 (2026-10-15 선생님)

**문제 풀기** — 실제 보기. 많이 고른 오답엔 「같이 볼까요?」. 문장 넣기는 지문 전체 + 칠한 핵심어.

## 1-1. 학생 단계 (고 1~2등급 · 중 3~5등급 · 초 6~8등급)

학생이 수업 목록 위에서 등급을 고른다(안 고르면 중). 레슨은 하나 — 화면에 `levels`를 달면 그 단계에게만 보인다.
**영어를 돕는 화면만 나눈다.** 수능은 내용 파악이 어렵다 — 문장 뜻 고르기, 요약·자유 해석, 그림, 쪼갠 설명은 고·중도 본다(2026-10-14 선생님).

| 화면 | 고 | 중 | 초 |
|---|:-:|:-:|:-:|
| 유형의 핵심(빈칸 위치, 재진술, 같은 쪽/반대 쪽, 보기 …) | ✓ | ✓ | ✓ |
| 문장 뜻 3지, 핵심어 요약·자유 해석, 그림, 쪼갠 설명 | ✓ | ✓ | ✓ |
| 주어·동사(+O/C/전목) 찾기 | 긴 문장(20단어~)만 | ✓ | ✓ |
| 가리키는 말 찾기, 헷갈리는 단어 뜻 3지 | | ✓ | ✓ |
| 단어·짧은 구절 뜻 3지 (등급 기준: **5~9등급만**, 중 3~4등급은 건너뜀) | | 5등급만 | ✓ |
| 해석 맞추기(짧은 문장) — 같은 자리의 뜻 3지와 돌려 냄 | 미정 | ✓ | ✓ |

**초급 기본(문장마다):** 맞추기 칸은 **핵심 논지 위주**(메인 주장의 핵심어)로 — 세부 수식어 칸은 넣지 않는다. 초급일수록 💡 Tip을 하나하나(as much A as B, ones가 가리키는 것, inter- 같은 접두사) (2026-10-15 선생님).
 「주어·동사(+O/C) 찾기 + 뜻 풀어 주기」 또는 「해석 맞추기」 중 **하나**를 모든 문장에 넣는다 —
같은 `slot`(`s<n>_basic`)에 두고 번갈아 낸다. 문장이 길면(20단어~) 맞추기는 **핵심어만 모은 문장**(`display`)으로.
이미 뜻 질문이 있는 문장은 뜻 풀기를 그 질문 **뒤에** 두고, 그 질문도 `meaning_check`. 열쇠 질문(답을 먼저 말하면 안 되는 것)은 `meaning_after`로 그 뒤에만.
그 문장의 💡 Tip은 초급 화면(주어·동사 찾기·맞추기)에도 같이 단다(`share_tips`) — 초급은 Tip이 달린 화면을 건너뛸 수 있어서 (2026-10-15 선생님).
도구: `scripts/lessons/beginner.py` (`add_basic`, `sv_step`, `m`, `fill_chunk_glosses`), 21번은 `beginner_21.py`. 9개 레슨 모두 적용 — 훑고 넘기는 문장·빈칸 문장·이미 모두에게 S·V가 있는 주어진 글은 뺐다 (2026-10-15 선생님)

그 밖에 중과 초를 가를 화면은 아직 없다 — 초에게만 더 줄 화면(쉬운 말 풀이, 한 번 더 쪼갠 설명)은 정해지면 `levels: ["초"]`로.
시범: 6월 34번(생성기 끝에서 단계를 단다). 테스트가 단계마다 끝까지 가는지 본다.

## 1-2. 헷갈리는 단어와 기능어 쓰임

- **누르면 보이는 뜻(모두에게):** 단어 뜻 + 연한 덩어리 뜻. 다의 기능어(to, for, as, that, which, so, but, yet, if, while, since)는
  사전 뜻 대신 **그 자리 쓰임**을 문장마다 나온 순서대로 적는다 — `content/tutor/function-senses/<레슨 id>.json`(빠지면 테스트가 잡는다)
- **먼저 짚어 주기(단계별):** 학생은 안다고 착각하는 단어는 안 누른다(2026-10-14 선생님 관찰). 함정 단어(모양 착각 spatial↔special,
  뜻 착각 bear, 쓰임 착각 yet=그러나)는 문장을 읽은 직후 3지로 묻는다. 목록은 `content/tutor/word-traps/함정단어.xlsx`
  (다정쌤이 후보를 채우고 선생님이 O/X·등급 확인) → 공용 목록이 되어 다른 지문에도 자동으로
- **엑셀 → 💡 Tip 자동 연결 (2026-10-16):** `npm run traps:export`가 엑셀을 `traps.json`으로 옮기고, 수업은 그 단어가 나오는
  문장의 화면마다 Tip을 띄운다(`src/tutor/policy/traps.ts`). **사용 O인 단어만**(비어 있는 후보는 안 띄운다 — 2026-10-16 선생님), 「누구에게」에 학생 단계가 없으면 안 띄운다.
  그 문장에 손으로 쓴 같은 단어 Tip이 있으면 그걸 쓴다. 단어 Tip은 되풀이 칩 노출 제한(3·5번)을 받지 않는다.
  **단어 Tip은 「자주 헷갈리는 단어 표시하기」 버튼으로** — 누르면 문장 속 그 단어에 물결 밑줄, 단어를 누르면 뜻 아래 💡 Tip(단어별로 본다). 기본은 꺼짐, 문장이 바뀌면 다시 꺼짐, 고르는 문제(pick) 중에는 버튼을 띄우지 않는다(밑줄이 답을 알려 줄 수 있다). 모아보기 목록 칩은 양이 많아 안 읽게 돼서 없앴다(2026-10-16 선생님). 칩에는 요령(단어에 안 붙은 것)·힌트만.
  **문장 아래 도구는 작은 칩 한 줄** — 🔊 듣기 · / 끊어읽기 · 〰 헷갈리는 단어 (문장 칸 밖). 「단어를 누르면 뜻이 나와요 · 모르는 단어는 ☆로 저장해요」는 지시문이라 말풍선 말고 칩 줄 아래 작은 글씨로(듣기가 보이는 처음 화면들), 단어 수는 쓰지 않는다. 「밑줄 친 단어를 눌러 보세요」는 처음 켰을 때 한 번만 같은 자리에 (2026-10-16 선생님: 버튼이 너무 많아 보인다).
  **문장을 처음 읽는 화면부터 뜬다**(2026-10-16 선생님) — 엑셀 단어 + 손으로 쓴 단어 Tip(문장의 단어에 붙은 것, `mark` 있음). 「순서 문제 요령」 같은 요령 칩(mark 없음)은 그 화면에서만. 그 문장에서 단어 **뜻을 묻는 질문**이 있으면 그 단어는 읽기 때 빼고(답이 샌다).
  **엑셀을 고치면 `npm run traps:export` → `npm run build`**

## 2. 화면 규칙 (테스트가 검사)

- **되풀이되는 💡 참고 칩**(「왜 핵심어만 보나요?」, 「빈칸 문제 요령」 등 같은 이름의 칩)은 학생(기기) 전체에서 **세 번**까지,
  한 번도 안 눌렀으면 **다섯 번**까지 보이고 그 뒤로는 띄우지 않는다(`src/tutor/tipExposure.ts`). 힌트 칩은 제외 (2026-10-14 선생님, 전체 정책)

- **칠하기(노랑·초록 표시)는 이해에 필요한 최소한으로** — 많이 칠하면 학생은 아무것도 안 본다. 덩어리 전체 대신 핵심 단어만
  (make reasoned … judgments → judgments). 단 difficult처럼 맥락 이해에 꼭 필요한 단어는 빼지 않는다 (2026-10-14 선생님)
  예외: 자유 해석·요약 화면의 노란 부분은 학생이 해석할 **범위**라 덩어리 그대로. 문장 넣기 답 고르기 화면은 `exam.passage_keywords`(단어만)

- 선생님 말 세 문장까지, 물음표 하나. 칭찬과 다음 질문은 다른 화면
- **여러 문장 중 한 문장을 가리킬 때**(주어진 글의 둘째 문장 등)는 따로 띄우지 않고 원래 화면에서 그 문장을 **[ ]** 로 묶는다(`bracket`) — 괄호는 보라색, 그 문장은 옅은 보라 바탕. 「이 문장」이 어디서 어디까지인지 보이게 (2026-10-15 선생님)
- **핵심어 = 주어·동사·목적어·보어 + 그 문장을 이해하는 데 필요한 말**인 경우가 많다. 부사구(in its tracks 등)는 보통 핵심어가 아니다 (2026-10-15 선생님)
- 정답을 시도 전에 말하지 않는다 — 틀렸을 때 설명에도 정답 보기 글을 넣지 않는다
- 틀리면 첫마디 「아쉽게도 틀렸어요.」 — **핵심어 고르기만 예외**: 「더 좋은 선택이 있어요.」(`keyword: true`)
- 자유 해석·요약은 한 군데까지 봐준다(틀렸다고 하지 않고 그 곳만 표시)
- 찾기 후보 덩어리는 화면에서 따로 누를 수 있어야 하고(덩어리 뜻), 덩어리 안 내용어는 단어 뜻이 있어야 한다
- 흐림은 콤마·대시 **두 개 사이**만, 주어+동사 있는 메인 문장은 흐리지 않는다. 기호는 「대시(—)」처럼 괄호로
- 시험지 아래 *로 풀어 준 단어는 핵심 단어가 아니다. Tip·문맥 뜻은 해설과 맞춰 본다(해설이 없으면 README에 「미대조」)

## 3. 생성기에 쓰는 도구 (지금은 생성기마다 복사해 쓴다 — 틀이 굳으면 공용 모듈로)

| 도구 | 하는 일 |
|---|---|
| `show(id, 말, button=…, before_read=…, display=…, tag=…, panel=…)` | 설명 한 화면. `before_read=True`면 그 문장을 읽기 **전에** |
| `choice(id, 질문, [(id, 보기, 정답?)…], 힌트, why=틀렸을 때)` | 3지 객관식(보기 2~3개) |
| `sv_pick(id, 후보, {덩어리: 역할}, 질문, wrong_by, 설명)` | 주어·동사(+O/C/전목) 찾기 |
| pick 한 개짜리 dict | 가리키는 말 찾기(`answers` 하나), 핵심어 찾기(`keyword: True`) |
| `key_summary(id, 예시, 규칙, 칠할 핵심어, 피드백, 포인트)` | 핵심어로 상황 요약(자유 응답, 규칙 채점). 칠할 핵심어엔 찾은 동사·보어·목적어를 기본으로 |
| `groups_board` / `sort_word` | 단어 지도와 끌어 넣기 |
| pick + `match: {ko: [...]}` | 해석 맞추기 — 한국어 칸(`{en, ko}`)에 영어 덩어리를 끌어 놓기. 짧은 문장만 (34번 `s1_match`). `levels=["중","초"]` |
| `slot="…"` | 같은 자리의 여러 방식 중 하나만 — 단계에 맞는 것 중 최근에 덜 한 방식. 적은 순서가 처음 우선 |
| 칠판 그림 | `public/assets/*.svg` + `panel={"kind": "picture", …}` |
| `story_boards.py` `STORIES` | 칠판 정리 장면(2~3문장마다). 손으로 쓴 레슨은 `python3 scripts/lessons/story_boards.py <id>` |

## 4. 2024년 3월 고3에서 처음 만든 유형 (2026-10-17, Claude 초안 — 선생님 검토 전)

`finish()`가 규칙 테스트와 같은 검사(물음표·세 문장, 정답 미리 말하기, 찾기 후보, 강조 구절, 덩어리 안 단어 뜻, 기능어 쓰임 개수)를
**쓰기 전에** 돌린다. 2024년 3월 레슨 15개(`gen_moeui_2024_03_*.py`)가 이걸 쓴다. 레슨 등록은 파일 이름으로 저절로(`lessons.ts`의 glob).

- **요약문**(`method.type = "summary"`, 40번) — 선생님이 고른 「지문 먼저 → 요약문」: 처음부터 읽으며 두 쪽 말을 칠판에 모은다
  (묶음 이름은 지문에서 나온 말까지만 — 요약문의 (A)(B) 자리는 쓰지 않는다) → 요약문(마지막 문장, `label: "요약문"`)에서
  (A)·(B)가 각각 칠판 어느 쪽인지 → 그 뜻의 말 3지 → 보기. 많이 고른 오답이 한 칸만 맞는 보기면 「두 칸 다 맞아야」를 짚는다
- **듣기 응답**(`method.type = "listening_response"`, 11·12번) — 선생님이 고른 「대본으로 독해식 수업」: 해설지 대본을 줄마다 문장으로
  (`label`: 남자의 첫 말 / 여자의 대답 / … / 남자의 응답), 마지막 응답 줄은 `________`. 푸는 법: 누가 무엇을 하고 있는지 →
  마지막 말이 무엇을 묻거나 권하는지 → 거기에 맞는 응답. 문장 아래 🔊 듣기로 소리도 듣는다. 주어·동사 찾기는 초급만
- **어휘** — [vocab.md](vocab.md)로 옮김. (예전 줄 「밑줄 점검표에 쌓는다(30번과 같게)」는 실제 30번과 달라서 표준을 정해야 한다 — vocab.md 「아직 정할 것」)
- **요약문** — [summary.md](summary.md)로 옮김
