# 유형별 수업 틀

모의고사 한 문제를 레슨으로 만들 때 따르는 틀. **공통 틀**(모든 유형) 위에 **유형 틀**(빈칸·순서·문장 넣기…)을 얹는다.
새 문제는 유형 틀의 체크리스트대로 생성기(`scripts/lessons/gen_*.py`)를 쓰고, 테스트(`npm run build`)가 규칙을 검사한다.

- 공통 틀: 이 문서
- 유형 틀: [빈칸](blank.md) · 순서(예정) · 문장 넣기(예정) · 밑줄 의미(예정) · 제목(예정) · 어휘(예정)
- 말투·화면 규칙의 근거: `docs/tutor/policy/AUTHORING_RULES.md`, 말투 `content/tutor/policy-copy/dajung/VOICE.md`

## 1. 수업 한 판의 모양 (공통)

```
지문 한눈에 보기 ─┬─ [분석하러 갈게요] ─ 도입 ─ (유형별: 읽기 전에 짚기) ─ 문장마다 ↓ ─ (유형별 마무리) ─ 문제 풀기 ─ 단어 체크 ─ 헷갈린 포인트
                  └─ 「바로 풀어 볼게요」 ─ 맞히면 [제대로 분석]/[핵심 정리]/[끝내기], 틀리면 분석으로
```

**도입** — 주제 한 줄(매번) + 풀이법 설명(그 유형을 **처음** 풀 때만, `method…` id).
도입 주제 화면엔 **칠판 그림**(`images.topic`, `public/assets/topic-*.svg`)으로 글 내용을 간단히 — 그림이 가장 좋고, 안 되면 간단한 표·구도.
칠판 글자는 **영어(괄호 한국어)**: Geography (지리학) — Where (어디). 아래 한 줄 물음으로 글을 암시(답은 말하지 않는다) (2026-10-14 선생님)

**문장마다** — 유형 틀이 정한 **열쇠 문장**은 아래를 다 하고, 나머지 문장은 읽기 + 한 줄 정리만 (빈칸: 재진술 문장이 열쇠)

1. **먼저 읽기** — 영어 문장만. 「다 읽었어요」는 1.2~3.5초 뒤에 뜬다
2. **주어·동사 찾기** — 회색 음영 덩어리를 눌러서(`pick` + `shade` + `roles`). 있으면 함께:
   목적어(O), 보어(C), **동사에 딸린** 전치사의 목적어(전목: learn **from experts**, associated **with geography**).
   꾸미는 전치사구 안의 명사(with tests, of skills)는 찾게 하지 않는다. 찾은 건 S·V·O·C·전목 표시로 남는다
3. **그 문장의 열쇠 한두 개** — 문장에 따라 고른다
   - 가리키는 말(One word, this task, the iteration) → 문장에서 찾아 누르기
   - 헷갈리는 뜻(appreciation, present, bear, scale) → 3지 객관식, 그다음 설명
   - 구조(not simply A; B, there are, Nor, 대시 앞뒤, but 뒤) → 짧은 설명 + Tip
   - 문장 뜻 → 3지 객관식 또는 **핵심어 요약**(노란 핵심어만 보고 직역 말고 상황을 한 줄로)
4. **그림·단어 지도**(필요할 때) — 칠판 서랍으로 크게. 단어 지도는 첫 단어만 넣고 나머지는 학생이 끌어 넣는다.
   이미 분류한 단어는 다시 분류하지 않는다

**칠판 정리** — **2~3문장마다 고정으로** 「지금까지 어떤 상황인지」 칠판에(`panel.kind = "story"`). 장면 한 줄 = 그림(이모지) +
영어 핵심어 + 한국어 한 줄, 장면이 쌓이고 이번에 붙은 것만 노랗게. 장면은 `scripts/lessons/story_boards.py`의 `STORIES`에 쓰고
생성기가 `add_story_boards`로 끼운다. **답을 말하지 않는다** — 밑줄 의미·제목처럼 요약이 곧 답이면 마지막 문장 앞에서 멈추고,
빈칸은 ____로, 순서·문장 넣기는 내용만 (2026-10-14 선생님, 모든 레슨)

**문제 풀기** — 실제 보기. 많이 고른 오답엔 「같이 볼까요?」. 문장 넣기는 지문 전체 + 칠한 핵심어.

## 1-1. 학생 단계 (고 1~2등급 · 중 3~5등급 · 초 6~8등급)

학생이 수업 목록 위에서 등급을 고른다(안 고르면 중). 레슨은 하나 — 화면에 `levels`를 달면 그 단계에게만 보인다.
**영어를 돕는 화면만 나눈다.** 수능은 내용 파악이 어렵다 — 문장 뜻 고르기, 요약·자유 해석, 그림, 쪼갠 설명은 고·중도 본다(2026-10-14 선생님).

| 화면 | 고 | 중 | 초 |
|---|:-:|:-:|:-:|
| 유형의 핵심(빈칸 위치, 재진술, 같은 쪽/반대 쪽, 보기 …) | ✓ | ✓ | ✓ |
| 문장 뜻 3지, 핵심어 요약·자유 해석, 그림, 쪼갠 설명 | ✓ | ✓ | ✓ |
| 주어·동사(+O/C/전목) 찾기 | 긴 문장(20단어~)만 | ✓ | ✓ |
| 가리키는 말 찾기, 헷갈리는 단어 뜻 3지 | | ✓ | ✓ |

중과 초를 가를 화면은 아직 없다 — 초에게만 더 줄 화면(쉬운 말 풀이, 한 번 더 쪼갠 설명)은 정해지면 `levels: ["초"]`로.
시범: 6월 34번(생성기 끝에서 단계를 단다). 테스트가 단계마다 끝까지 가는지 본다.

## 1-2. 헷갈리는 단어와 기능어 쓰임

- **누르면 보이는 뜻(모두에게):** 단어 뜻 + 연한 덩어리 뜻. 다의 기능어(to, for, as, that, which, so, but, yet, if, while, since)는
  사전 뜻 대신 **그 자리 쓰임**을 문장마다 나온 순서대로 적는다 — `content/tutor/function-senses/<레슨 id>.json`(빠지면 테스트가 잡는다)
- **먼저 짚어 주기(단계별):** 학생은 안다고 착각하는 단어는 안 누른다(2026-10-14 선생님 관찰). 함정 단어(모양 착각 spatial↔special,
  뜻 착각 bear, 쓰임 착각 yet=그러나)는 문장을 읽은 직후 3지로 묻는다. 목록은 `content/tutor/word-traps/함정단어.xlsx`
  (다정쌤이 후보를 채우고 선생님이 O/X·등급 확인) → 공용 목록이 되어 다른 지문에도 자동으로

## 2. 화면 규칙 (테스트가 검사)

- **되풀이되는 💡 참고 칩**(「왜 핵심어만 보나요?」, 「빈칸 문제 요령」 등 같은 이름의 칩)은 학생(기기) 전체에서 **세 번**까지,
  한 번도 안 눌렀으면 **다섯 번**까지 보이고 그 뒤로는 띄우지 않는다(`src/tutor/tipExposure.ts`). 힌트 칩은 제외 (2026-10-14 선생님, 전체 정책)

- **칠하기(노랑·초록 표시)는 이해에 필요한 최소한으로** — 많이 칠하면 학생은 아무것도 안 본다. 덩어리 전체 대신 핵심 단어만
  (make reasoned … judgments → judgments). 단 difficult처럼 맥락 이해에 꼭 필요한 단어는 빼지 않는다 (2026-10-14 선생님)
  예외: 자유 해석·요약 화면의 노란 부분은 학생이 해석할 **범위**라 덩어리 그대로. 문장 넣기 답 고르기 화면은 `exam.passage_keywords`(단어만)

- 선생님 말 세 문장까지, 물음표 하나. 칭찬과 다음 질문은 다른 화면
- 정답을 시도 전에 말하지 않는다 — 틀렸을 때 설명에도 정답 보기 글을 넣지 않는다
- 틀리면 첫마디 「아쉽게도 틀렸어요.」 — **핵심어 고르기만 예외**: 「더 좋은 선택이 있어요.」(`keyword: true`)
- 자유 해석·요약은 한 군데까지 봐준다(틀렸다고 하지 않고 그 곳만 표시)
- 찾기 후보 덩어리는 화면에서 따로 누를 수 있어야 하고(덩어리 뜻), 덩어리 안 내용어는 단어 뜻이 있어야 한다
- 흐림은 콤마·대시 **두 개 사이**만, 주어+동사 있는 메인 문장은 흐리지 않는다. 기호는 「대시(—)」처럼 괄호로
- 시험지 아래 *로 풀어 준 단어는 핵심 단어가 아니다. Tip·문맥 뜻은 해설과 맞춰 본다(해설이 없으면 README에 「미대조」)

## 3. 생성기에 쓰는 도구 (지금은 생성기마다 복사해 쓴다 — 틀이 굳으면 공용 모듈로)

| 도구 | 하는 일 |
|---|---|
| `show(id, 말, button=…, before_read=…, display=…, tag=…, panel=…)` | 설명 한 화면. `before_read=True`면 그 문장을 읽기 **전에** |
| `choice(id, 질문, [(id, 보기, 정답?)…], 힌트, why=틀렸을 때)` | 3지 객관식(보기 2~3개) |
| `sv_pick(id, 후보, {덩어리: 역할}, 질문, wrong_by, 설명)` | 주어·동사(+O/C/전목) 찾기 |
| pick 한 개짜리 dict | 가리키는 말 찾기(`answers` 하나), 핵심어 찾기(`keyword: True`) |
| `key_summary(id, 예시, 규칙, 칠할 핵심어, 피드백, 포인트)` | 핵심어로 상황 요약(자유 응답, 규칙 채점). 칠할 핵심어엔 찾은 동사·보어·목적어를 기본으로 |
| `groups_board` / `sort_word` | 단어 지도와 끌어 넣기 |
| 칠판 그림 | `public/assets/*.svg` + `panel={"kind": "picture", …}` |
| `story_boards.py` `STORIES` | 칠판 정리 장면(2~3문장마다). 손으로 쓴 레슨은 `python3 scripts/lessons/story_boards.py <id>` |
