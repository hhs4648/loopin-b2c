# 어휘 유형 틀 (v1 — 2026-10-21 정리)

「문맥상 낱말의 쓰임이 적절하지 않은 것」. 기준 레슨: **2026년 3월 30번**(`gen_moeui_2026_03_30.py`, 가장 많이 고친 레슨).
2024년 3월 30·42번, 2022년 3월 30번은 같은 틀의 Claude 초안(`exam_kit` 사용). 공통 틀은 [README](README.md).
`method.type = "word_in_context"`, 풀이법 칠판 `METHOD_IMAGES["vocab"]`.

## 푸는 법 (선생님)

1. **요지 잡기** — 첫 문장(들)에서 글의 주장 (30번: 이름을 붙이면 하나하나의 특징은 무시된다)
2. **두 그룹으로 나누기** — 핵심어를 왼쪽/오른쪽 두 그룹에 **학생이 직접 끌어 넣는다**. 반대 신호(not·yet·Not so)가 단서
3. **밑줄 단어 맞춰 보기** — 밑줄 낱말이 흐름에 맞는 그룹 쪽인지. 맞지 않는 하나가 답

도입 풀이법: 「어휘 문제는 단어 뜻만 보면 다 맞아 보여요. 문장마다 흐름을 잡아야 틀린 단어가 보여요.」

## 화면 순서

| # | 화면 | 만드는 법 | 30번 예 |
|---|---|---|---|
| 0 | 도입 | 주제 그림(매번) + 풀이법(처음만), `read_first`, `read_button: "분석하러 갈게요"` | 「이름을 붙이면 무엇이 사라질까요?」 |
| 1 | 요지 문장 | 같은 뜻 말 묶기(`show` + `highlight`) → **핵심 구절 한 줄은 칠판 없이 글과 함께** → 그다음 칠판과 「○○는 어느 그룹?」(`choice` + `panel.sort`) → 정리 지도 | s1_group → s1_abstract → s1_q → s1_map |
| 2 | 그룹 쌓기 문장 | 「X는 어느 그룹일까요?」 2지 → 정리(새 단어만 노랗게) | s5_sort (Lawn) |
| 3 | 과정·반대 관계 | 과정 말(abstract away, leave out)은 그룹 단어가 아니라 **화살표**(`process`), yet·Not so는 **↔ 대조**(`contrast`) | s3_map, s7_yet, s9_contrast |

| 5 | 정답 밑줄 문장 | 흐름(그룹)만 묻고 **맞다/틀리다는 말하지 않는다** | 5문장 ②: Lawn 그룹만 |

## 만들 때 체크리스트

- [ ] 두 그룹 이름과 끌어 넣기 글(`SORT_LEFT`/`SORT_RIGHT`)을 먼저 정했다. 학생이 답하기 전에 칠판에 답을 보여 주지 않는다
- [ ] 과정 말은 화살표, 반대 신호는 ↔
- [ ] 정답 밑줄은 분석 중에 맞다/틀리다를 말하지 않는다
- [ ] 정답이 아닌 밑줄의 「문맥에 맞아요」 화면엔 칠판을 띄우지 않는다
- [ ] 글쓴이가 중립이면 평가 뒤집기(+/−)를 넣지 않는다(30번은 X, 2026-10-15)
- [ ] 초급 해석 맞추기 칸에 **밑줄 낱말 뜻을 넣지 않는다**(답이 드러남, 2026-10-15)
- [ ] 많이 고른 오답은 `review(rate, say, panel)`, 나머지는 `option_feedback`
- [ ] 「~둘게요/뒀어요」 같은 화면 중계 말, 「어디서 헷갈렸어요?」 되묻기 없음
- [ ] Tip·뜻은 해설지와 대조(present A to B 오류 사례, 2026-10-06), 각주 단어는 핵심어에서 뺐다
- [ ] 대시가 하나뿐이면 흐리지 않는다(dash 규칙)
- [ ] `npm run policy:copy stamp <id>` → `npm run build`

## 정한 것

- 학생이 끌어 넣는다, 정답은 분석 중에 언급하지 않는다, 많이 고른 오답(④ 38%·③ 29%)은 따로 챙긴다 (2026-10-06)
- 평가 뒤집기는 30번에 적용하지 않는다 — 글쓴이 중립 (2026-10-15)
- 결론 화면 칠판 빼기, 요지 한 줄은 칠판 없이 먼저, not 꿀팁 (2026-10-20)

## 아직 정할 것 / 어긋난 것

- **밑줄 점검표 vs 그룹 지도:** README 예전 줄은 「밑줄 점검표(`rows`)에 쌓는다(30번과 같게)」였지만, 정작 2026 30번은 점검표 없이 그룹 지도만 쓴다. 2024·2022 초안은 점검표를 쓴다 — 어느 쪽을 표준으로 할지
- 2024·2022 어휘 레슨 문제 질문에 「밑줄 점검표를 떠올려 봐요」가 남아 있다
- 2026 30번 생성기는 `exam_kit`을 안 쓰고 도구를 직접 정의 — 틀이 굳으면 `exam_kit`으로 옮기기
- `option_points`(헷갈린 포인트 한 줄)는 30번에만 있다 — 다른 레슨에도 둘지
- 고·중·초 차이는 공통 표 말고 정한 것 없음
