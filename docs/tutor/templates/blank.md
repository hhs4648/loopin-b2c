# 빈칸 유형 틀 (v1 — 2026-10-14 확정)

기준 레슨: **2026학년도 6월 모의평가 34번**(`gen_mopyeong_2026_06_34.py`, 빈칸이 가운데) ·
**2026년 3월 33번**(`gen_moeui_2026_03_33.py`, 빈칸이 마지막). 공통 틀은 [README](README.md).

## 푸는 법 (선생님)

1. 빈칸이 **어디 있고 무엇을 묻는지**만 먼저 확인한다 — 답을 정하지 않는다
2. **처음부터 순서대로** 읽으며, 같은 말이 다른 말로 반복되는 것(재진술)을 모은다
3. 빈칸 문장에 도착하면: 빈칸이 **글쓴이 주장과 같은 쪽인지, 반대 쪽인지** 파악한다(반전 단서 But·However·not·without, 좋은 말+/나쁜 말−)
4. 모은 말을 **다른 말로 바꿔 쓴 보기**를 고른다

> 빈칸 문장만 따로 먼저 풀게 하지 않는 이유: 빈칸 문장은 앞 문장을 받는 말(Moving up in scale 등)이 많아서
> 앞을 안 읽으면 3~4등급은 무엇을 찾을지 모른 채 들어간다. 위치만 짚고 순서대로 읽는다(2026-10-14 선생님).
