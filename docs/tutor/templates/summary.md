# 요약문 유형 틀 (v0.1 — 초안, 2026-10-21 정리)

> **선생님이 정한 건 푸는 법 「지문 먼저 → 요약문」(2026-10-17) 하나뿐이다.** 화면 구성은 전부 Claude 초안이고 선생님 검토 전.

기준 레슨: 2024년 3월 40번(`gen_moeui_2024_03_40.py`), 2022년 3월 40번(같은 틀). 공통 틀은 [README](README.md).
`method = {"type": "summary", "labels": ["지문 먼저 읽기", "두 쪽 말 모으기", "(A)(B) 맞추기"]}`.

## 푸는 법

1. 지문을 처음부터 읽으며 글쓴이 주장을 잡는다
2. 대립하는 **두 쪽 말**을 칠판 두 칸에 모은다
3. 요약문에서 (A)·(B)가 각각 칠판 **어느 쪽**인지 정한다
4. 그 뜻의 말을 고르고, **두 칸이 다 맞는** 보기를 고른다

## 만들 때 체크리스트

- [ ] 칠판 묶음 이름은 지문에 나온 말까지만 — 요약문 (A)(B) 자리 말·정답 보기 단어 금지
- [ ] 첫 칠판은 두 쪽이 생긴 뒤에
- [ ] 요약문 문장에 `label: "요약문"`(10분 모의고사가 이걸로 요약문을 지문 뒤에 붙인다)
- [ ] 선택률로 (A)만 틀린 오답 / (B)만 틀린 오답을 나눠 해설. 2022는 `wrong_rate_source`
- [ ] 각주(*) 단어 빼기, 해설 대조, `stamp` → `npm run build`
