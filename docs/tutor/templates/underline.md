# 밑줄 의미 유형 틀 (v1 — 2026-10-21 정리)

「밑줄 친 부분이 다음 글에서 의미하는 바」. 기준 레슨: **2026년 3월 21번**(`moeui-2026-03-21-music-researchers`, 앱 전체의 기준 레슨 —
손으로 만든 JSON, 초급 화면은 `beginner_21.py`). 2024·2022년 3월 21번은 같은 틀의 Claude 초안(`exam_kit`).
공통 틀은 [README](README.md). `method = {"type": "underline_meaning", "labels": ["핵심 단어 찾기", "관계 잡기"]}`, 그림 `METHOD_IMAGES["underline"]`.

## 푸는 법 (선생님)

1. **핵심 단어만 골라 요지를 빠르게** — 「밑줄 문제는 핵심 단어 위주로 지문의 요지를 빠르게 파악하면 좋아요.」
2. **핵심 단어 사이의 관계** — 대조(without)·같은 쪽 말을 **두 그룹 단어 지도**로 모은다
3. 밑줄에 도착하면 그 뜻이 **지도의 어느 쪽 말인지**로 판단 (따옴표는 「진짜 그 말이 아님」)
4. 그 뜻을 **바꿔 쓴 보기** — 보기는 색칠된 `keywords`만 본다

## 화면 순서

| # | 화면 | 만드는 법 | 21번 예 |
|---|---|---|---|
| 0 | 미리보기 | 문제·지문·보기 한 화면, [분석하러 갈게요] / 「바로 풀어 볼게요」 | |
| 1 | 도입 | 주제 그림(매번) → 「수능 문제는 시간 싸움이에요.」 → 밑줄 풀이법(처음 3번만, `intro_times: 3`) | 「좋은 음악은 새로워야 할까요?」 |
| 2 | 첫 문장 **핵심어 고르기** | `pick` + `keyword: true`(틀려도 「더 좋은 선택이 있어요」). 함정은 덧붙이는 말(in fact, strictly speaking) | brilliant musician · innovator · without · inventor |
| 3 | 관계 묻기 | `choice` 2지 「유의어 / 대조」 | 대조 |
| 4 | 단어 지도 열기 | `panel.kind: "groups"`(왼쪽/오른쪽, 이번에 붙은 말 `fresh`) — **읽은 데까지만, 단어만** | innovator 쪽 ↔ inventor 쪽 |
| 5 | 문장마다 | 가리키는 말 → 「어느 쪽 단어?」 2지 → 짧고 중요한 문장은 자유 해석(`translate`) | 2문장 In such cases → discoveries |
| 6 | 풀어 쓴 문장·예시·구호 | `shaded`/`faded` + [자세히 볼래요](`detail_button`·`optional_of`) | 4·5문장 |
| 7 | 칠판 정리 | 2~3문장마다 `story`, **밑줄 문장 앞에서 멈춤**(요약이 곧 답) | |
| 8 | **밑줄 문장** | 하이라이트 → 밑줄 뜻 질문 + Tip(따옴표, 숙어) → 지도 완성 → 「문제 풀러 갈게요」 | 진짜 연구자 / **연구자 흉내** |
| 9 | 보기 | 보기마다 `keywords`·`ko`. 오답 해설은 「지도에 없는 이야기 / 반대 / 글 단어로 헷갈림」 중 하나 | ⑤ science는 지도에도 있지만… |

초급: 문장마다 S·V+뜻 또는 해석 맞추기(`levels: ["초"]`), 훑는 문장은 뺀다. **밑줄 문장 맞추기엔 글자 그대로 해석만 — 속뜻은 넣지 않는다.**

## 만들 때 체크리스트

- [ ] `exam.underline`이 문장 안에 그대로 있다(`exam_kit` 검사)
- [ ] 첫 문장 핵심어 `pick` — 함정은 덧붙이는 말, 각주(*) 단어는 핵심어 아님
- [ ] **두 그룹 축을 먼저 정했다**(대조 / 감각+마음 / 두 시대 …)
- [ ] 지도는 읽은 데까지만·단어만, 그룹 라벨은 단계별로 늘린다(inventor 쪽 → ·새로움 → ·새로움·진보). 묶음 이름·캡션으로 답을 미리 말하지 않는다
- [ ] 풀어 쓴 문장·예시·구호는 흐리게/음영으로 넘긴다
- [ ] 밑줄 문장에 따옴표·비유 Tip, 칠판 정리는 밑줄 앞에서 멈춘다
- [ ] 보기 `keywords`·`ko`, 많이 고른 오답 `review`(오답률 표)
- [ ] 배경지식 설명을 넣지 않는다 — 문제 맞히는 데 필요한 영어만 (2026-09-29)
- [ ] `npm run policy:copy stamp <id>` → `npm run build`

## 정한 것

- 배경지식 빼기, 모든 문장을 분석하지 않기, 지문은 고난도 유지 (2026-09-29 피드백)
- 21번을 기준 레슨으로, 풀이법 칠판은 처음 3번만, 두 그룹 지도 + 보기 키워드 색칠 (2026-10-05)
- 미리보기 먼저, 문장은 먼저 혼자 읽기, 문장 1은 핵심어 4개 누르기로 시작, 칭찬은 따로 한 화면 (2026-10-08)
- 칠판에는 읽은 데까지만, 그룹 라벨은 단계별 (2026-10-14)
- 질문 화면 칠판에선 새로 붙은 표시(`fresh`) 숨김, 빈 칠판은 띄우지 않음 (2026-10-18)

## 아직 정할 것

- **「밑줄 뜻」 3지 화면을 따로 둘지** — 2026 21번은 2지(진짜/흉내) + 지도, 2024·2022 초안은 3지
