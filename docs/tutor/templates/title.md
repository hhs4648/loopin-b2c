기준 레슨: **2026년 3월 24번**(`gen_moeui_2026_03_24.py`, 제목). 2024년 3월 24번(제목)·22번(요지 `gist`)·23번(주제 `topic`)·41번(제목)은
이 틀을 따른 Claude 초안. 공통 틀은 [README](README.md).
`method = {"type": "title" | "topic" | "gist", "labels": ["핵심어 찾기", "글쓴이 생각 잡기"]}`.

## 푸는 법 (선생님)

1. 문장마다 **핵심어**를 찾고 뜻을 잡는다
2. **글쓴이 생각**을 잡는다 — 대비되는 두 쪽을 칠판 두 칸(`groups`)에 모은다, 좋은 말(+)·나쁜 말(−)
3. 글 전체를 **한 줄로** 묶는다
4. 그 한 줄을 **다른 말로 바꾼** 제목(주제·요지)을 고른다

도입 풀이법: 「제목 문제는 글 전체를 한 줄로 묶는 말을 찾는 거예요. 문장마다 핵심어를 찾고 글쓴이 생각을 잡아 볼게요.」

## 만들 때 체크리스트

- [ ] 핵심어를 미리 칠하지 않는다 — 학생이 찾는 문장은 `keys`(지문당 10개 안팎, `keys_checked: true`는 선생님 확인 뒤에만)
- [ ] **핵심어만 가지고 해석(`translate` `method: 0`)·주어·동사 찾기를 만들지 않는다** — 둘 다 엔진이 건너뛴다 (2026-10-20: 「뭘 하라는 건지 모르겠대」)
- [ ] 자유 응답은 `method: 1`(생각 쓰기)만, 짧고 중요한 문장에서
- [ ] 두 그룹 칠판은 읽은 데까지만, 정답 보기 말을 묶음 이름에 쓰지 않는다. 빈 칠판을 갑자기 띄우지 않는다
- [ ] 글 전체 한 줄은 마지막 문장 뒤, 칠판 정리는 마지막 문장 앞에서 멈춤
- [ ] 보기 `keywords`·`ko`, 많이 고른 오답 `review`
- [ ] 각주(*) 단어는 핵심어에서 빼고 해설과 대조, 헷갈리는 단어(TRAPS: body → 양, work → 작품)
- [ ] `add_match`, `add_refers`, `stamp` → `npm run build`
