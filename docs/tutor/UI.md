# UI 셸 — 상냥쌤 프로토타입을 Loopin 다정쌤에 그대로 쓴다

시각 원본 (카카오톡 HTML, 7MB 번들이라 저장소에는 넣지 않음):

- `학습첫화면_대답버튼.html` → **화면 1: 교실 대화**
- `상냥쌤 문장 학습.html` → **화면 1 + 화면 2: 문장 학습**

저장소 안 추출본: `docs/tutor/refs/` (폰트·이미지 빠진 slim HTML).

프로토타입 캐릭터 이름은 "상냥한 선생님"이다. Loopin 본제품 튜터 이름은 **다정쌤**. UI 셸·색·레이아웃은 프로토타입을 따르고, 카피만 다정쌤으로 바꾼다. haksup 앱 UI를 가져오지 않는다.

## 공통

- 캔버스: **390 × 844** 모바일. 바깥은 `#1d1a1f`, 안은 크림 교실 `#f7efe6`.
- UI 폰트: Noto Sans KR. 선생님 대사·영어 문장: **Gowun Dodum**.
- 포인트 핑크: `#ef7a93` / 호버 `#e2607d`. 본문 `#2b2430`. 보조 `#8a7f88`.
- 입력·칩·말풍선은 알약(999px) 또는 큰 radius. 그림자 `rgba(60,30,20,…)`.
- 애니메이션: 캐릭터 `bob`, 말풍선 `pop`, 타이핑 점 `dot`, 타이머 점 `blink`.

## 화면 1 — 교실 대화 (인트로 · 청크 루프의 “말” 턴)

교실 벽/마루 + 화이트보드(자석 분홍/파랑/노랑, 마커) + 시계 + 화분.
캐릭터는 화면 중앙 하단, 위쪽에 **흰 말풍선**(꼬리 아래). 자막 모드는 옵션.

| 요소 | 역할 |
|------|------|
| 좌측 칩 | 다정쌤 + `오늘의 학습 · n단계` |
| 경과 타이머 | `mm:ss`, 빨간 점 점멸 |
| X | 학습 종료 |
| 선생님 말풍선 | `message`. 대기 중엔 분홍 점 3개 |
| 학생 말풍선 | 마지막 답, 오른쪽 분홍 `#ef7a93` |
| 빠른 대답 버튼 | `buttons[]`. 오른쪽 정렬, 핑크 테두리 알약. 타이핑 중엔 숨김 |
| 하단 바 | placeholder `선생님께 답해 보세요…` + 마이크 + 보내기 |

빠른 대답 예시(프로토타입): `네, 좋아요!` / `힌트 주세요` / `다시 설명해 주세요` — 실제 수업에서는 레슨 JSON·튜터 출력의 `buttons`가 여기를 채운다. `잘 모르겠어요`는 항상 후보.

## 화면 2 — 문장 학습 (해석 입력 · 청크 보여주기)

흰 교실 배경. 영어 문장을 **크게** 가운데. 선생님은 작은 아바타+말풍선으로 하단.

| 요소 | 역할 |
|------|------|
| ← | 교실 대화로 |
| `문장 학습 · 1 / 5` | 청크/문장 진행 점 |
| X | 학습 종료 |
| 영어 문장 | 현재 청크 또는 전체 문장, Gowun Dodum ~40px |
| 듣기 | TTS. 옆에 word count |
| 선생님 말풍선 | 다정쌤 한 턴 (`message`) |
| 빠른 버튼 | 예: `다 읽었어요`, `힌트 주세요` → 레슨/프롬프트 buttons |
| 하단 바 | placeholder `해석을 적어 보세요…` + 따라읽기 녹음 + 보내기 |

청크 해석을 받을 때는 이 화면이 기본이다. 되묻기·2지선다만 있을 때는 화면 1로 돌아가도 된다.

## LLM 출력과의 연결

이미 정한 UI JSON과 1:1이다.

```json
{ "message": "말풍선", "buttons": ["잘 모르겠어요"], "effect": null }
```

- `message` → 선생님 말풍선 (화면 1 큰 버블 / 화면 2 하단 버블)
- `buttons` → 빠른 대답 알약. 빈 배열이면 자유 입력만
- `effect: "light"` → 학생이 스스로 고친 턴. 화이트보드/말풍선 하이라이트 (나중에)

채팅 로그를 길게 쌓지 않는다. 선생님은 **현재 한 줄**, 학생은 **마지막 한 줄**만 보여 주는 형식이 프로토타입의 핵심이다.
