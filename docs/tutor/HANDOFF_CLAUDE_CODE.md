# Claude Code에게 맡기는 지시

이 문서를 **첫 메시지에 붙여 넣거나**, 레포를 연 뒤 `CLAUDE.md`와 함께 읽게 하면 된다.

---

너는 Loopin B2C 저장소에서 **다정쌤 영어 해석 튜터**를 이어서 구현한다.

이 제품은 haksup이 아니다. haksup 화면·카피·채점·튜터를 복사하지 마라.
이미 데모 앱과 규격이 있다. 처음부터 다시 만들지 마라. `npm run dev`로 동작을 확인한 다음, 규격을 깨지 않는 선에서만 코드를 바꿔라.

## 목표 (우선순위)

1. **지금 있는 데모를 유지한 채** 구조만 프로덕션에 가깝게 정리한다. (엔진이 액션을 고르고, UI는 TutorView만 그린다.)
2. **LLM 어댑터를 붙일 자리를 만든다.** 아직 키가 없으면 인터페이스만. 호출부는 `TREAT_UNEXPECTED`(진단 D)와 부분 정답 B에만 연결한다.
3. C(예상 오류 P2/P3)와 E(체크리스트 유도)와 miss 카운트는 **절대 LLM에 맡기지 않는다.**
4. 고유명사는 수업 시작 시 미리 제시하고, 문장에 나오면 칩/하이라이트로 보여 준다. Lewis Ltd.를 한국어로 바꾸라고 채점하지 않는다.
5. 말풍선은 선생님 위. 문장 학습 화면에서 설명·되묻기도 그 화면을 유지한다.

사람이 “LLM 붙여”라고 하면:

- 시스템 = `content/tutor/frame.json` + **현재 unit만** 직렬화 + SessionState 요약 + 이번 `action`
- 유저 = 학생 발화 그대로
- 어시스턴트 = `{ message, buttons, effect }` JSON
- 가드레일: 모범 해석·아직 안 알려 준 항목의 답이 있으면 폐기, 한 턴 질문 1개, 해요체

사람이 “새 지문”이라고 하면 시스템 프롬프트를 고치지 말고 `content/tutor/lessons/`에 JSON만 추가한다.

## 확인 방법

- `npm run dev` 후 퇴사 편지 7문장 흐름
- 문장 1: 정답형 / serve=봉사 / It=그것 / 엉뚱한 입력(=힌트)
- 문장 3: Lewis Ltd. 칩이 보이고, 이름 해석을 요구하지 않음
- 잘 모르겠어요 3번 → 힌트 1,2,3 순서 (2에서 정답 주면 실패)
- 한 턴에 질문이 두 개면 실패
