# 2026년 시행 기출 — 오답률 Top 10 검수 목록 (2026-10-21)

새로 만든 레슨 23개. 모두 **Claude 초안**이고 선생님 검토 전이다.
`npm run build`(타입검사 → 테스트 852개 → 빌드) 통과. 개발 중엔 `?lesson=<id>`로 바로 연다.
각 생성기(`scripts/lessons/gen_*.py`) 머리말에도 같은 「선생님이 확인할 점」이 있다.

공통으로 지킨 것: S·V 찾기 스텝 없음, 핵심어 나열형 해석 없음, 모든 문장 끊어읽기(/ · S·V·O·C · [ ]),
해설지 번역과 단어 뜻·Tip 대조, * 풀이 단어는 핵심어에서 뺌, 많이 고른 오답에 「같이 자세히 볼래요」.
**헷갈리는 단어는 함정단어 엑셀에 넣지 않았다** — 레슨마다 적어 둔 후보를 보시고 넣을 것만 골라 주세요.

오답률 출처: 2026년 3월 = EBS 공개 자료(앱 엑셀), 6월·9월 = 메가스터디 채점(상위권 표본이라 EBS보다 정답률이 평균 11%p 높다).

6. **끊어읽기에서 같은 말이 두 번 나오면(it’s 등) 뒤의 S·V 표시를 뺐다** — 화면 자리가 어긋나서. 표시 도구를 고칠지
