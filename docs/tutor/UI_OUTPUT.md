# UI 연동 출력 형식 (나중 단계)

화면 셸은 [`UI.md`](UI.md)다. 교실 대화 + 문장 학습 두 장. 채팅을 스크롤하지 않고 선생님 한 줄·학생 마지막 한 줄만 보여 준다.

앱에 붙을 때 시스템 프롬프트 **절대 규칙 아래**에 다음을 추가하면 버튼 렌더링이 가능해집니다.

대화만 테스트할 때는 넣지 마세요. JSON 강제 출력이 해요체 테스트와 `[기록]` 라인을 깨뜨립니다.

```
모든 응답은 JSON으로 출력한다:
{"message": "말풍선 내용", "buttons": ["잘 모르겠어요", ...], "effect": null | "light"}
- buttons: 학생에게 보여줄 선택지 (2지선다, "그렇군요~", "더 알고 싶어요" 등). 자유 입력만 받을 때는 [].
- effect: 학생이 오류를 스스로 교정해낸 순간에만 "light" (깨우침의 빛 이펙트).
```

레슨 JSON의 `choices[].label`이 `buttons` 후보입니다. 기본 탈출 버튼 `"잘 모르겠어요"`는 자유 입력 턴에도 앱이 넣을 수 있습니다.

`effect: "light"`는 정답을 튜터가 알려준 뒤가 아니라, 학생이 **스스로 고친 턴**에만 켭니다.
