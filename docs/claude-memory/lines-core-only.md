대사는 핵심 위주로 짧게(2026-10-15 선생님). 예: 「이제 (A)·(B)·(C)를 시험지 순서대로 읽어요. ~~시험지는 단락 순서가 섞여 있어서 서로 바로 이어지지 않아요.~~ 단락마다 첫머리와 끝을 잘 봐 두면 좋아요.」 — 가운데 문장은 누구나 아는 말이라 뺐다. 같은 날 「이렇게 평소와 반대로 평가하는 말은 꼭 표시해 둬요」도 과부하라 뺐다.

**Why:** 세 문장까지 허용이라고 세 문장을 채우면 학생이 핵심을 놓친다. 당연한 말·메타 요령은 읽는 부담만 늘린다.

**How to apply:** 대사를 쓸 때 문장마다 「이게 없으면 학생이 모르는가?」를 묻고, 아니면 뺀다. 일반화(「긍정으로 끝나면 반전」)·뻔한 사실·요령 훈계는 쓰지 않는다. [[evaluation-flip]] [[praise-separate-from-question]]
