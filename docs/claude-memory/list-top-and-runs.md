2026-10-20 선생님 요청(여러 번에 걸쳐 확정):
- 문제 앞에 「Top1, Top2…」(회차 안 오답률 순위, 15위까지)
- 카드에는 **본 횟수 + 최근 정답 여부 + 공부 시간**만 — 「3번 중 1번 맞힘」은 기분 나쁘다, 수험생은 같은 지문을 여러 번 보는 게 당연
- 맞힘/틀림은 **분석 뒤 제출한 답** 기준(이 앱 목적이 분석), 분석 없이 끝냈을 때만 바로 풀기 답
- **「봤다」(완료) = 답 제출(바로 풀기 포함) 또는 마지막 문장까지 옴** — 중간 문장 skip해도 마지막 문장까지 왔으면 봄
- 중간에 나가면 **멈춘 곳부터 이어서** (버튼 「이어서 하기」), 시계도 이어 감
- 정렬: 진행 중(최근 위) → 안 한 것(오답률 순) → 끝낸 것(최근 위) — 이 해석은 Claude가 정함

**Why:** 학생이 이어 할 문제를 바로 찾고, 반복 학습을 기죽지 않게 보여 주려고.
**How to apply:** 기록은 src/tutor/progress.ts (`dajung.runs`는 cloud.ts로 서버 동기화, 이어 하기 자리 `dajung.resume`은 기기에만). 세션 자리는 session.ts `snapshot()/restore()` — 레슨 모양(문장·스텝 id)이 바뀌면 처음부터. 수업이 끝까지(마지막 화면) 가면 자리를 지운다 — 그래서 「봤다」 뒤에도 끝 화면 전까지는 이어 하기가 남는다.
