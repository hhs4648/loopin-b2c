어법(grammar) 레슨은 **주어·동사 찾기를 빼고** 밑줄 그어진 문법만 자세히 설명한다 (2026-10-20 선생님). 도입 말: "어법 문제는 다른 문제들과 달리 문법만 보면 돼요. 그래서 이번 유형은 문법 설명 위주로 갈게요." 풀이법 이름 ① 밑줄 문법 확인 ② 틀린 것 고르기.

선생님이 준 본보기(2022-03 29번 ① nor), 한 문법마다:
1. 한국어 뜻 (nor = ~도 아니다)
2. 모양과 문법 이름 (완성된 문장, nor + 동사 + 주어 = '도치')
3. 헷갈리는 세부 (동사가 둘 이상이면 맨 앞 하나만 앞으로: has survived → has it survived)
4. 함께 오는 조건 (nor 앞은 늘 부정문)
5. 💡 Tip으로 짝/반대말 (so = ~도 그렇다)
6. 바로 연습 — 두 문장 합치기 빈칸 (객관식, 보기마다 틀린 이유 다르게)
7. 「이 문법을 나중에 좀 더 연습할까요?」 [네]/[괜찮아요] → 네면 연습할 문법으로 기록 → 보충학습실에서 drill 10문제 (처음 객관식, 뒤로 갈수록 주관식 섞기)

**Why:** 어법은 해석보다 규칙을 정확히 아는 게 점수로 이어진다. 연습은 학생이 원할 때만 쌓는다.
**How to apply:** 설명이 4개 이어지면 칠판 표에 한 줄씩 쌓는다 [[three-lines-then-board]]. 스텝은 show `practice: "<drill id>"`, drill 자료는 `content/tutor/grammar-drills/<id>.json`. 정답 밑줄은 시도 전 맞다/틀리다 말하지 않기. 2024-03 29번에는 아직 안 넣음.

drill 시작 전엔 짧은 규칙 카드(「부정문일 땐 → nor + 동사 + 주어 / 긍정문일 땐 → so + 동사 + 주어」처럼 언제 → 어떻게, 2026-10-20 선생님). 자료 `intro` 필드. 문법은 큰 묶음(category) 아래 세트 여럿: 「nor / so」 = nor 기본 개념 10 · nor vs so 10 · nor vs neither 10 · 작문 10 (2026-10-20 선생님 결정). 작문은 한국어 보고 뒷부분만 쓰기(규칙 채점, 맞는 모양 여러 개), 순서는 추천만 하고 잠그지 않음, 수업의 「더 연습할까요?」는 묶음 통째로. 자료 `grammar-drills/categories/<id>.json`. 기존 좋은 문제는 빼지 말고 세트를 늘린다 — 틀릴 만한 경우를 하나씩 다 다루고 싶어 함.

**③ consisting 재구성 (2026-10-20 선생님) — 어법 설명의 본보기:** 보기에 없는 말(consisted)을 먼저 꺼내지 않는다(학생은 「갑자기 왜?」). 순서: 이 밑줄이 묻는 것(동사냐 분사냐) → 동사·분사 차이 표(동사 ~하다: learn/learned·wrote/will learn/is learning, 분사 ~하는·~된: learning/learned·written) + 표 아래 [나중에 보충학습실에서 더 깊이 공부할게요](show `practice_button`) → 암기(한 문장에 동사는 하나, and·or·when 접속사 있어야 추가) → 「그럼 보기 ③은 어법상 맞을까요, 틀릴까요?」 → 해설(It seems·Greek music was 두 쌍, 접속사 없음 → 분사) → 이름(완성된 문장 + , + 분사 = 분사구문) → [심화: consisted는 왜 안 될까요?](detail_button + optional_of). 이미 담은 문법은 뒤 「더 연습할까요?」를 건너뜀.

**드문 유형은 정답 뒤에 알려 주기 (2026-10-20 선생님):** 29번 ②(more·as 짝)는 모의고사 어법에 거의 안 나오는 유형이라 오답률 1위 — 보통은 분사 구분 등을 묻는다. 정답 해설 다음 한 화면(exam `answer_note`)으로 짧게 말한다. 정답 전에는 말하지 않는다.
