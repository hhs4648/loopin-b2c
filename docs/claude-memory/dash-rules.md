- **대시가 하나뿐인 구절은 흐리지 않는다.** 흐림(빼도 되는 삽입)은 대시(—) 두 개 사이만. 대시 하나 뒤는 앞말을 풀어 쓰거나 예시를 드는 본문이다(39번 주어진 문장 「—without … shared」, 30번 8문장 「—making a daisy chain …」을 잘못 흐렸다가 고침). 테스트가 막는다(「흐림(삽입)은 대시(—)가 두 개일 때만」).
- **학생에게 「대시」라고 할 땐 꼭 「대시(—)」.** 학생들이 대시가 뭔지 모른다. 콤마도 「콤마(,)」처럼.

**Why:** 2026-10-13 사용자 지적 (39번 주어진 문장을 삽입절로 잘못 파악, 학생들이 '대시'라는 말을 모름).

**How to apply:** 새 레슨에서 faded를 넣기 전에 대시 개수 확인. 대사·Tip에 기호 이름을 쓸 땐 괄호로 기호를 보인다. [[main-clause-never-faded]]
