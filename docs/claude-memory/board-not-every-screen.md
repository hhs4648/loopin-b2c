2026-10-20 선생님: 30번 3문장 「그래서 ①differences는 문맥에 맞아요」 화면의 칠판을 아예 빼라고 함. "전반적으로 칠판이 너무 많아서 영어를 못 읽겠어."

**Why:** 칠판이 열리면 지문이 가려진다. 새 정보가 없는 결론·정리 대사까지 칠판을 띄우면 학생이 영어 문장을 읽는 시간이 사라진다.

**How to apply:** 칠판(panel)은 새 단어가 붙거나 학생이 끌어 넣는 화면에만. 바로 앞 칠판과 같은 내용을 캡션만 바꿔 다시 보여 주는 show 스텝은 panel을 뺀다. 첫 설명 대사도 칠판 없이, 칠판은 그다음 대사에서([[three-lines-then-board]] [[board-read-so-far-only]] [[minimal-highlight]]).
