2026-09-29, 사용자가 21번 공유 HTML로 다른 사람들에게 피드백을 받음: **너무 길다, 배경지식 설명이 영어 학습과 연관이 없다, 중간에 도망가고 싶다.** 피드백 준 사람들은 **수능 준비생이 아니었다** — "어렵다"는 반응을 타깃 반응으로 보지 말 것.

같은 날 정한 방향:
- **차별점은 수능.** 18번 같은 쉬운 지문으로 내려가지 않는다. 지문은 어렵게, 수업은 짧게
- **지문 전체를 한 과정에 담지 않는다** (사용자 확정). 한 지문을 3분 안팎 회차 여러 개로 쪼개고, 회차마다 작은 성공으로 끝낸다
- 모든 화면은 "이 문제를 맞히는 데 필요한 영어 한 가지"를 가르치거나 뺀다. 배경지식(데카르트·17세기) 설명 없음
- 난이도 계단이 필요하면 같은 유형의 고2 모의고사, 또는 오답률 낮은 문항부터

**Why:** 지금 21번은 버튼 30번 이상, 문장 8개를 전부 분석한다.

**How to apply:** 새 지문도 회차 쪼개기 기준으로 만든다. `docs/tutor/policy/AUTHORING_RULES.md`의 도입 5단계·스텝 기본형은 이 피드백 이전 것이라 21번을 다시 짜면서 같이 고친다. [[teaching-policy-direction]]
