2026-10-21 선생님이 짠 **온보딩** — 처음 가입한(코스가 없는) 학생이 로그인 직후 보는 화면. 상담실과 따로다(처음에 상담실을 고쳤다가 선생님이 「첫 상담이 아니고 처음 가입할 때, 온보딩」이라고 바로잡음 → 상담실은 원래대로). 화면 src/components/SignupWelcome.tsx, App의 welcome 상태, 규칙 src/tutor/counsel.ts:
0. 이름 묻기(이미 있으면 건너뜀, parseName으로 「민준이요」→민준, 못 알아보면 되묻지 않음)
1. 인사: 「수능 전에 꼭 필요한 것만 … 오답률 Top 10 문제들만 모았어요💛」 → 「같이 분석하면서 1등급 사고방식」 → 「단어는 필수 … 수능 전까지 계속 볼 수 있게」
2. 학년(n수·고3·고2·고1·중학생) → 최근 등급(1~9) → 최근 기출부터/이전 기출부터(연도는 앱에 있는 기출에서 자동) → 평가원만(6·9월·수능)/교육청까지(3·5·7·10월)
3. 5등급 이하(grade ≥ 5)면 묻지 않고 2점짜리부터(skipThree)
4. 「좋아요! 다 됐어요💛 … 아직 낯설 테니까, {코스 첫 시험} 중 오답률이 가장 높았던 문제부터 예시로 함께 봐요」 → [같이 볼래요] → 그 문제를 **바로 분석**(지문 미리보기에 [분석하러 갈게요]만 — 풀기·시간 재기 아님, 2026-10-21 선생님 「첫 온보딩은 분석으로 연결」)

선생님은 반말로 써 줬지만 다정쌤은 해요체(CLAUDE.md)라 해요체로 옮김. 목표 등급·공부 시간·아쉬운 유형 질문은 뺐다(목표=등급-1, 시간 30분 기본).

**Why:** 첫 화면에서 앱의 가치(Top 10·분석·단어)를 먼저 말하고, 질문은 코스를 짜는 데 필요한 것만.
**How to apply:** 선생님이 말한 「2026년 9월」은 아직 앱에 없다(2026-10-21 기준 기출: 2026학년도 6월 평가원(레슨 2개라 10분 묶음 없음)·2026/2024/2022 3월 교육청). 그래서 예시 시험은 이름을 박지 않고 코스 첫 시험으로 자동. 평가원 묶음이 없으면 「평가원만」도 교육청까지 넣고 마지막 화면에서 알려 준다. [[course-ten-min]] [[home-village-counsel]]

**줄임 (2026-10-21 선생님 「줄여줘」): 다섯 번 누르면 첫 문제** — 이름 → 소개 한 화면(세 줄: Top 10 · 같이 분석 1등급 사고방식 · 필수 단어) → 최근 등급 → 기출 순서 → 다 됐어요 → 바로 분석. 학년·기출 범위 질문은 지금 코스에 영향이 없어 뺐다(답 칸 year·scope와 counsel.ts 규칙은 남겨 둠 — 평가원 기출이 들어오면 범위 질문을 다시 넣는다). 5등급 이하가 「최근 기출부터」를 골라도 2026년 3월은 2점 문제 묶음이 없어 2024년 3월이 첫 예시가 된다.

**학습자 구분 (2026-10-22 선생님, 지표용)** — 소개 다음에 「지금 어디에 해당해요?」 [고3·N수생][고1·2][중학생][일반인] 한 번. `loopin.learner_group`(suneung·high12·middle·adult)으로 브라우저+서버 learner_state에 저장(`src/tutor/learner-group.ts`). 중학생·일반인은 등급 질문을 건너뛰어(등급 모름) 누르는 수는 그대로. 코스에는 아직 영향 없음. 소개 둘째 줄은 「다양한 성격의 쌤들과 1:1 수업으로 집중 코치받아요」로 바뀜.

**(폐기 2026-10-22 — 선생님 「별로야 못쓸듯」, 아래 최신 참고) 예시 문제 = 핵심어로 한 번에 풀기 먼저** — 8~9등급 「찍는 법 알려 줘」 피드백 + 학생 성향(빠르게/꼼꼼히)이 둘로 갈림. 온보딩에서 성향을 묻지 않고: 미리보기에 핵심어(keys ?? emphasis) 칠함 → 다정쌤 「칠한 핵심어만 이어 읽어도 … 같은 뜻을 담은 보기를 골라 봐요」(처음만 길게) → 바로 보기 고르기(밑에 「분석부터 할게요」) → 맞히면 [분석하기]/[다음 문제로], 틀리면 분석으로. 고른 것을 `loopin.study_style`(fast/deep 횟수·last, 서버 동기화)에 기록 — 다음 단계: 이 값으로 시작 버튼 순서 맞추기. 코드 App `startOnboardingExample`·ReadPassage `quick`·`src/tutor/study-style.ts`.

**(바뀜 — 아래 최신 참고) 예시 문제 = 데카르트의 나무 고정 (2026-10-22 선생님)** — 오답률 1위(9월 34번)는 너무 어렵고 답이 납득 안 돼 이탈 걱정, 번역의 낯섦·음악 연구자는 추상적 → 그림으로 이해되는 지문. 보관본(archive/2025-03-21-descartes)을 `moeui-2025-03-21-descartes-tree`로 되살림(세트 moeui-2025-03-21, 2025년 3월 컬렉션, 1문제라 10분 코스엔 안 들어감). `counsel.ts` ONBOARDING_SET_ID. 레슨 `quick_hint`(나무 그림 tree_filled + 「뿌리는 철학… 가운데서 잘렸다면 무엇과 무엇이 끊어진 걸까요?」 + 칠할 말 roots·trunk·branches and fruit). 예전 도입(오답률 자신 있나요·데카르트 아나요·17세기 배경지식)은 뺐다. 분석 본문은 같은 날 다듬음: 주어 고르기·구조·겹치는 정리·think 화면 9개 삭제(32→19스텝 아님, 화면 수 기준 약 절반), 대사 핵심만, 틀리면 「아쉽게도 틀렸어요.」.

**예시 분석 = 기능 가이드 (2026-10-21 선생님, 사용자 테스트: 단어 누르면 뜻 나오는 걸 몰랐다)** — 온보딩 예시 문제에서 `OnboardingCoach`가 기능이 처음 보일 때 하나씩 짚는다(분홍 테두리 + 검은 말풍선, 직접 누르거나 [알겠어요]면 끝, 기기에 기억 `loopin.coach.v1`): 미리보기 [분석하러] → 단어 누르기 → ☆ → 듣기 → 끊어읽기 → 💡 → 잘 모르겠어요 → 전체 지문 → ‹ ›, 칠판 손잡이는 BoardDrawer가. 확인용 주소 `?onboarding`(코스 있어도 온보딩 처음부터, 길잡이 초기화). 새 작은 기능이 생기면 COACHES에 한 줄 보탠다.

**최신 (2026-10-22 선생님) — 예시 문제 = 2026년 3월 30번 이름과 차이, 분석만, 끝나면 마을 둘러보기**
- 데카르트는 「너무 옛날에 만든 문제라 별로」 → 선생님이 손 많이 댄 30번(`ONBOARDING_SET_ID = "moeui-2026-03-30"`). 데카르트 레슨은 2025년 3월 목록에 남아 있음.
- 흐름: 지문 한눈에 미리보기 → [분석하러 갈게요]만(바로 풀기 없음) → 분석. **정답을 먼저 풀게 하지 말고 분석하게 이끈다.** 핵심어로 먼저 풀기(quick·study_style)는 App·ReadPassage에 코드만 남아 있고 안 쓴다.
- 예시가 끝나면(중간에 나가도) 시험(10분 모의고사)으로 보내지 않고 **홈**으로 → App `tour`: 교무실 짚기 → 교무실 첫 말 「여기서 함께 공부할 선생님을 고를 수 있어요. 선생님과 함께 공부한 시간이 늘어날수록 친밀도가 올라가요.」(StaffRoom intro, 반말 쌤은 speak) → 연습실 짚기(들어가기 전에 빈 칸만 맛보기 넣음 `src/tutor/practiceSamples.ts`: 30번 단어 4개·6문장 연습할 문장·nor/so 문법) → 단어·문장·문법 탭 차례로 짚기 → 나오면 상담실 짚기 → 상담실 「다시 상담하기」로 코스 짜기(화면 아래라 굴려서 보여 줌). 코치 문구는 OnboardingCoach `TOUR`.
