2026-10-16 선생님: 3월 36번 (A) 둘째 문장(Dennett suggests that …)은 수능용으로는 빠르게 skip해도 되지만, 내신용으로 공부할 땐 하나하나 꼼꼼히 해야 한다 → 내신용/수능용 분석 정도를 다르게 해야 할지도.

**지금 하고 있는 분석 정도(S·V·O·C 찾기, that 안 S·V, 꾸밈 구조, 핵심어, 메인/뒷받침 등)는 수능용에서도 기본** — 줄이지 않는다(2026-10-16 선생님). 내신은 그 위에 더 얹는 것.

**How to apply:** 아직 결정 아님. 만든다면 학생 단계(levels)처럼 「공부 목적(수능/내신)」을 고르게 하고, 내신 전용 화면(뒷받침 문장 S·V·that 안 S·V, 구문 Tip, 전체 해석)을 `purpose: ["내신"]`처럼 단다. 지금 레슨은 수능 기준(뒷받침·예시는 핵심어만). [[beginner-basic-per-sentence]] [[svo-finding]]
