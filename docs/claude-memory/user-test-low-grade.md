2026-10-20 선생님이 8~9등급이었던 20대 초반 사용자에게 써보게 하고 관찰: 한 지문(풀기+분석) 20분. 집중 잘하고 재밌어했지만 **시험 문제 자체는 거의 못 풀었고**, 분석 과정의 **작은 문제(choice 스텝)에 더 관심**. 작은 문제를 몇 개 틀렸는지 보고 싶고, 틀린 것을 다시 보고 싶어 함.

**Why:** 하위 등급에게는 수능 문제 한 개가 아니라 분석 속 작은 문제가 "풀 수 있는 단위"다. 성취감과 복습 욕구가 거기서 생긴다.

**How to apply:** 작은 문제 점수(맞힌 수/전체)를 수업 끝과 진도표에 보여 주고, 틀린 작은 문제만 다시 푸는 복습을 만들 것(기록은 이미 세션 records·lessonlogs에 있음). 하위 등급은 시간 재서 풀기보다 분석이 중심. 관련: [[course-ten-min]] [[wrong-reason-later]] [[length-vs-patience]]
