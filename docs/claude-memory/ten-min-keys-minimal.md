2026년 3월 33번(profound building) 지문의 핵심어(`emphasis`)를 선생님이 직접 골라 줌: 지문 전체에서 **1~2문장만** — architectural · guides action · space · facilitates or prohibits / This · predetermines · behavior · but · also · guides · emotions. 3~8문장은 하나도 안 침. "너무 많이 치지 말자."

**Why:** 핵심어만 읽고 풀기는 "이것만 보면 답이 나온다"는 최소 집합이어야 함. 문장마다 2~4개씩 치면 다 읽는 것과 같아서 의미가 없음.

**How to apply:** 레슨 생성기 EMPHASIS는 지문당 10개 안팎, 주장 문장(대개 첫 1~2문장이나 빈칸 근처)만. 연결어(but·also·This)도 포함. 다른 14개 Top5 레슨의 emphasis(다른 세션이 문장마다 넣음)도 이 기준으로 줄여야 함. 관련: [[minimal-highlight]] [[course-ten-min]]
