2026-10-15 선생님(36번 검수):
- **핵심어** = 주어·동사·목적어·보어 + 그 문장을 이해하는 데 필요한 다른 단어. 예: Dennett suggests 문장 → it is useful / consideration-generator-squelchers / items / stop / deliberation. in its tracks는 핵심어 아님.
- **여러 문장 중 한 문장을 가리킬 때**는 따로 띄우지 말고 원래 화면에서 그 문장을 [ ]로 묶는다(스텝 `bracket`). 공통 규칙.
- **초급 해석 맞추기**는 한국어-영어를 핵심 논지 위주로(세부 수식어 칸 X).
- **초급일수록 Tip을 하나하나**: as much A as B, ones가 가리키는 것, inter- 접두사 같은 것.

**How to apply:** 핵심어 칠하기·핵심어 고르기 답·요약 칸을 정할 때 이 기준. [[minimal-highlight]] [[beginner-basic-per-sentence]] [[svo-finding]]
