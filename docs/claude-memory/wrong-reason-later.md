2026-10-20 선생님: 많이 고른 오답 뒤 「그래서 ③이 아니에요. 어디서 헷갈렸어요?」 + 이유 버튼 3개는 학생이 너무 피곤해서 뺐다— 같은 날 레슨 데이터의 질문·선택지(option_review.ask·choices)도 모두 지움(선생님: Claude가 만든 것이고 대부분 별로). exam_kit review()는 이제 (rate, say, panel). **헷갈린 곳을 기록하는 것 자체는 매우 좋다** — 질문 방식이 적절하지 않을 뿐. 다른 방법은 나중에 같이 정하기로 함 (지금은 기록만).

**Why:** 선생님이 기록의 가치는 높게 봄(맞춤 강조·ML 연구). 다만 되묻는 질문은 수업을 길고 피곤하게 만든다.
**How to apply:** 선생님이 이 주제를 꺼내면 이어서 한다. 후보로 꺼낼 만한 것(아직 제안 안 함): 학생에게 묻지 않고 이미 남는 행동 기록으로 추정 — 고른 오답 보기, 그 문장 분석 중 틀린 스텝·힌트 연 것·「잘 모르겠어요」, 단어 눌러 본 것(vocab_click), 머문 시간. 질문 없이 skill에 쌓는 방식. [[exam-submit-and-summaries]] [[free-translation-step]]
