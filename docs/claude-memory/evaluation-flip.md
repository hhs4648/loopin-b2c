평소와 반대로 평가되는 말은 꼭 짚는다(2026-10-15 선생님, 공통 규칙). 예: 3월 36번 conversation-stoppers(대화를 멈추게 하는 것) — 보통은 나쁘게 보지만 글에서 one benefit·their value와 같이 쓰여 좋은 것(+).

**적용 조건(둘 다):** ① 글의 핵심어일 것 — 예시 속 지나가는 말은 X ② 글쓴이 입장이 한쪽으로 확고할 것. 30번(이름 붙이기 vs 구체적 특징 — 각자 장단점, 저자 중립)은 적용 안 함(2026-10-15 선생님).

**평가는 주장 맥락으로 읽되 설명은 가볍게:** 36번 둘째 문장(We are rational creatures, always able to ask for justification … has served us well in many contexts)은 「대화를 멈추는 게 좋을 때도 있다」는 앞 맥락으로 읽는다 — 늘 이유를 따지는 건 많은 상황에서 도움이 되지만 멈춤과는 약간 반대, 「평소엔 이유를 따지지만 때로는 멈출 수 있는 게 좋을 수도 있다」 정도만 짚는다. 내가 has served us well을 +로 단정한 것, 「−에 가깝다」 분석, 「두 문장 관계?」 질문, 「평소와 반대로 평가하는 말은 꼭 표시해 둬요」, 「긍정으로 끝나면 다음은 반전」 일반화는 모두 선생님이 뺐다(과부하·일반화, 2026-10-15).

**Why:** 학생은 단어의 평소 느낌(대화 멈춤 = 나쁨)으로 읽어서 글쓴이 태도를 거꾸로 잡는다. 순서·빈칸에서 +/− 판단이 흐름의 단서라 틀리면 다 틀린다.

**How to apply:** 그 말이 나온 문장에서 「글쓴이는 ○○를 좋게 볼까요, 나쁘게 볼까요?」 2지 → 칭찬과 분리된 설명 화면에서 「보통은 나쁘게 보지만 여기선 benefit·value와 함께 쓰여 +」 + 평가어 칠하기 + signs 표시. docs/tutor/templates/README.md §1-3. [[blank-same-or-opposite]] [[praise-separate-from-question]]
