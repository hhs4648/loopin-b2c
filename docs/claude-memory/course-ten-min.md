2026-10-20 선생님 결정: 상담실 코스·홈 「오늘의 10분」의 단위는 **10분 모의고사** — 시험마다 오답률 Top 10(장문 41~45·듣기 제외)을 5문제씩 (1)(2)로. 순서는 **3·6·9월 모의고사 최근 것부터(5개년) → 수능 → 5·6·10월 등 나머지**, 「수능 기출부터」 선택 가능. 세 회마다 **틀린 문제 복습 칸**(맞힌 건 빼고, 복습에서 맞히면 다음엔 안 나옴), 코스 끝나도 틀린 게 남는 한 복습 계속(다회독). 시작 화면에서 「바로 풀기 / 분석 먼저 하고 풀기」 선택. 하루 목표: 5문제 + 분석 + 단어. 학생이 실제로 쓸 시간은 수능 전 ~3주.

**Why:** 수능 한 달 전엔 "뭐 풀지" 고르는 시간이 낭비, 10분이라 매일 가능. 같은 문제 그대로 반복하면 답을 외우므로 맞힌 건 뺀다.

2026-10-20 추가: **진도표**(상담실 코스 화면 → 진도표, `ProgressBoard.tsx`·`seen.ts`) — 시험마다 문제 칸(안 봄/맞힘/틀림/보기만), 자주 틀리는 유형; **3점은 어디서나 표시**(번호 줄·문제 줄·목록·진도표); 5등급 이하는 상담에서 「2점부터 할래요」 → 2점 문제만 코스(`ten-<시험>-2pt-N`).

2026-10-20 저녁 확정: 회차마다 **1 실전 풀기(풀기 전 주요 단어 화면이 자동으로 한 번, 학습으로 안 침) → 2 분석 → 3 단어 연습(별표·보라펜 단어 위주 테스트, 모자라면 주요 단어) → 4 틀린 문제 복습**(힌트 없이 다시 풀기 → 또 틀리면 이유 입력·기록 → 분석 다시 보기, `wrongReview.ts`). 세 회마다 끼우던 복습 칸은 뺌. 코스 화면은 연도 구분줄 → 「시험 오답률 Top 10 풀기」 → (1)(2). 상담에선 아쉬운 유형·수능 먼저를 묻지 않음(수능은 3·6·9월과 합쳐 최근순). 수업 끝 「1/2/3주 뒤 다시 보기」 화면 삭제(기록만 남김). CTA 문구 「바로 시작하기」, 다시 상담 버튼은 맨 아래.

2026-10-20 밤: **첫 방문**(기록 없음)엔 홈 CTA가 「다정쌤과 한 문제 분석해 보기 · 5분」 → 코스 첫 회 오답률 1위 문제를 분석 모드로 → 끝나면 안내 한 줄과 함께 코스 첫 회 10분 모의고사 시작 화면(`isFirstVisit/onboardingSet/firstMockId`, App `onboarding`). 시작 화면은 풀던 게 있으면 「이어서 풀게요」 하나(처음부터 다시 없음). 제목 「2026년 3월 10분 모의고사-1」.

2026-10-20 밤 2차 확정: (1)(2) 나누기 폐기 → **시험마다 오답률 Top 10 한 묶음**(`ten-<시험>`), 문제는 **Top1부터** 나열, 문제마다 「풀기」(낱개 `ten-<시험>-q<번호>`, 2~3분)와 「분석」을 따로, 아래 분홍 버튼은 「20분 미니 모의고사 · 10문제 쭉 이어 풀기」. 기록은 전체·낱개를 합쳐 최근 답 기준(`combinedAnswers`). 시작 화면의 「분석 먼저」 버튼 삭제.

2026-10-20 밤 3차 확정(최종): 시험 묶음 「오답률 Top 10 완전 정복」 하나만 누르면 Top1~10이 뜨고, **문제마다 단어 미리 보기 → 시간 재서 풀기(「풀기는 건너뛰고 분석부터」 가능) → 바로 분석 → 다음 문제**로 이어짐(App `flow`, `nextProblemOf` = 분석 안 끝난 첫 문제). 풀기/분석 따로 버튼·20분 미니 버튼·「분석 먼저」 진입은 뺌. 코스 카드엔 「이어서 하기 · N번」 하나.

**How to apply:** 문항은 레슨 JSON에서 자동(`src/tutor/tenmin.ts`), 순서·복습 칸은 `counsel.ts` `defaultCourse/courseStatus/nextMockOf`, 복습 id `ten-review-<n>`/`ten-review-end-<k>`(`mini.ts`). 레슨을 추가하면 코스도 늘어남. 시간(10분)·5문제·세 회마다 복습은 보면서 조정 예정. 관련: [[mini-mock]] [[home-village-counsel]]

2026-10-20 밤 4차: **가입(로그인 통과) 직후 계획이 없으면 상담실로 바로**(App `autoCounsel`, 서버 값 받은 뒤 판단) → 상담 마지막 「좋아요, 바로 시작할래요」를 누르면 코스 화면 없이 **첫 문제 단어 미리 보기부터**(`CounselRoom.finish` → `onOpenMini(첫 시험-q번호, "words")`). **문제당 제한시간은 등급별**: 1~2등급 2분 · 3~4등급 3분 · 5~6등급 4분 · 7~9등급 5분, 모르면 3분(`counsel.ts` `minutesPerItem/withPlanMinutes`, 10분 모의고사 id에만, 3점 가산 없음). 풀기 화면의 위쪽 「제출」은 뺐고 마지막 문항의 버튼도 「다음 ›」 하나(안 푼 문항 있을 때만 묻기). 결과의 「다정쌤과 이 문제 분석하기」 버튼은 제목만(설명 줄 삭제 — 정보가 많다).

2026-10-20 밤 5차: 코스 화면은 **진행 중인 시험 묶음 하나만 펼치고** 나머지는 제목 줄(▸)만 — 누르면 펼침(`CourseView` `open`). 미니에서 분석하러 넘어갈 때 **「지문 한눈에 미리보기」는 그대로 보여 주고** 「바로 풀어 볼게요」만 뺀다(App `startSet(set, true)`, 자동 넘김 삭제).

2026-10-20 밤 6차(선생님): **문제 풀기는 「지문 한눈에 미리보기」 화면에서** — 단어 미리 보기 → 미리보기(큰 버튼 「시간 재서 풀어 볼게요 · N분」, 밑줄 「풀기는 건너뛰고 분석부터」) → 보기를 고르면 레슨이 그대로 분석으로 이어짐(풀기와 분석이 한 화면). 시계는 위 제목 자리(초과하면 +MM:SS), 답을 고르면 멈추고 `ten-<시험>-q<번호>` 기록으로 저장(App `courseExam`, `ReadPassage` `course` prop). 낱개 미니 모의고사 화면은 코스에서 안 씀. 묶음 카드 안에 **「실제 시험처럼 시간 재서 미니 모의고사 풀기 · N문제 M분」** 버튼(전체 묶음을 MiniMockView로, 시간은 등급별 문제당 분 × 문제 수 — 1~2등급 10문제 20분).

2026-10-20 밤 7차(선생님: 버튼이 너무 많다): 코스 문제의 미리보기는 **들어가자마자 카운트다운이 돌고 보기를 바로 고를 수 있다**(App이 「바로 풀어 볼게요」를 자동으로 보냄). 분홍 버튼은 **「분석하기」 하나**(답 안 고르고 눌러도 분석으로, 세션 exam_first에서 readButton 받음). 보기를 고르면 맞음/틀림을 짧게 보여 주고 분석으로. 「시간 재서 풀어 볼게요 · N분」·「풀기는 건너뛰고 분석부터」는 뺌.

2026-10-20 밤 8차(선생님): 코스 풀기 화면(미리보기)에 **펜 줄**(모르는 단어 보라펜·형광펜·끊어읽기, `MiniMarks` 그대로, `ReadPassage` course + `PassageFull` mark) — 보라펜 단어는 풀이 기록 `unknown`과 단어장에. 미리보기 지문은 **문장마다 ▶ 듣기**(코스 아닐 때도). 풀기 안내 대사는 모든 레슨 「실제 시험처럼 풀어 봐요. 풀지 않고 분석 먼저 하고 풀어도 돼요.」(exam_kit·생성기·JSON 일괄, 대사 전부 재stamp). 단어 미리 보기는 단어마다 🔊 발음(`sayWord`), 「문제 풀러 갈게요」는 목록 아래. 단어 뜻은 「손의」처럼 조각 말고 「손으로 하는, 손을 쓰는」처럼 뜻이 통하게. 30번 s1_q는 글과 같이 보는 한 줄(s1_abstract) → 칠판+질문(s1_q)으로 나눔.

2026-10-20 밤 9차(선생님 OK, 초급에 더 의미): **작은 문제 점수** — 분석 속 질문(choice·pick·translate) 첫 시도만 세서 수업 끝 헷갈린 포인트 화면에 「작은 문제 N개 중 M개 맞혔어요」(세션 `small`, view `smallScore`, 회차 기록 `run.small`, 코스 행 「작은 문제 M/N」). **「틀린 것 다시 풀기」** 버튼 → 틀린 choice 스텝을 칠판 없이 문장+질문+보기만으로 다시(세션 stage `retry`), 끝에 「틀렸던 작은 문제 n개 중 m개를 다시 맞혔어요」. 작은 문제 난이도는 그대로(쉽게 만들지 않기).
