1. 화면이 하는 일을 말로 중계하지 않는다 — 「칠판에 붙여 둘게요」「밑줄 점검표에 붙여 둘게요」「단어 지도에 넣어 둘게요」 삭제 (2026-10-20 선생님, 모든 레슨). 2026-10-20에 생성기 14개에서 지움 (이전 버전 비교용 epistemic-communities-v1은 손대지 않음).
2. 서로 다른 이야기는 한 말풍선 안에서도 줄을 바꾼다 — 「보충학습실에 담아 뒀어요.」+「①has는 맞아요.」를 한 줄에 붙이면 어색. 말풍선은 white-space: pre-line, 엔진은 `\n`으로 잇는다.
3. 어법 레슨에서 맞는 밑줄을 「①has는 맞아요」로 알려 주지 말고, 설명·연습 끝에 「그럼 보기 ①은 어법상 맞을까요, 틀릴까요?」로 고르게 한다. 「더 연습할까요?」보다 먼저.

**Why:** 학생에게 들어가는 정보가 이미 많다. 세세한 진행 안내는 집중을 흐린다. 스스로 판단하게 하는 게 학습에 더 좋다.
**How to apply:** 대사를 쓸 때 「~둘게요/뒀어요」로 화면 동작을 알리는 문장이 있으면 지운다(학생에게 필요한 기능 안내 「보충학습실에 담아 뒀어요」는 둔다). [[grammar-type-lessons]] [[natural-korean-grammar]]
