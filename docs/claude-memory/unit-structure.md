2026-09-30 사용자 확정: 문제를 누르면 **작은 학습 단위 목록**이 나온다 — (1) 단어 1 (2) 단어 2 (3) 핵심 문장 찾기 (4) 주어·동사 찾기 (5) 문법 (6) 실전 풀기. 단위가 끝나면 「여기서 쉴게요 / 다음」 (한 번에 이어서 하되 끊을 수 있게 — 하루 한 회차 방식은 채택 안 함).

실전 풀기는 **보기를 세 개만 먼저** (정답 + 많이 고른 오답 둘), 학생이 「보기 다 볼래요」를 누를 때만 다섯 개. 사용자 제안이다.

**Why:** [[q21-simplify-feedback]] — 지문 전체를 한 수업에 담으면 길어서 도망가고 싶다.

**How to apply:** 규칙은 `docs/tutor/policy/AUTHORING_RULES.md` §0. 21번은 단위 1(단어)·6(실전 풀기)만 만들었고 2~5는 「준비 중」 — 이어서 만들 때 사용자에게 단위 1을 눌러 본 반응부터 물을 것. 통째로 된 예전 21번 레슨은 목록에서 내리고 회귀용으로 남겼다.
