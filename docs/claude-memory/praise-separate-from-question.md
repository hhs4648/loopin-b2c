정답·오답을 알려 주는 말(「맞아요.」「다 찾았어요!」「잘 찾았어요.」)은 **다음 질문과 분리해서** 말한다. 코드가 알아서 한다: `praiseThenNext` → 칭찬만 한 화면(`praiseOnly`, 버튼 없이 1.3초) → 다음 질문. 문장 끝이면 문장 칭찬 화면(「맞아요! N번째 문장을 아주 잘 이해했어요!」)이 대신한다.

**Why:** 2026-10-08 사용자 요청. 맞았다는 말은 아이들에게 긍정적 강화가 되는 중요한 말이라 따로 보여야 한다 (나중에 캐릭터 표정·모션도 바꿀 예정).

**How to apply:** 대사를 쓸 때 ask에 칭찬을 섞지 말고, praise는 짧게 따로 둔다. [[reference-lesson-2026-q21]]
