화면 제목·버튼·안내 글은 담백하게. AI 같은 말투(「주요 단어 먼저」, 「다 봤어요, 풀게요」, 「가볍게 확인해보세요」 같은 꾸민 말)를 쓰지 않는다.
예: 「주요 단어 먼저」→「지문 단어 미리 보기」, 「다 봤어요, 풀게요」→「문제 풀러 갈게요」 (2026-10-20).

**Why:** 선생님이 "너무 ai같은 말투라서 싫어, 앞으로도 빼줘"라고 강하게 말함.
**How to apply:** 새 UI 문구·대사를 쓸 때마다 적용하고, 기존 화면에서 눈에 띄면 시키지 않아도 고쳐서 알린다. [[natural-korean-grammar]] [[no-meta-narration]] [[lines-core-only]]와 같은 방향.
