칠판에는 지금까지 진행된 문장에서 알 수 있는 정보만 넣는다(2026-10-14 선생님, 공통 규칙). 6월 34번 단어 지도의 「공간 · 어디에 어떻게 놓여 있나」·「모두 같은 말 — 어디에, 어떻게 배치돼 있나」는 "안 중요해 보인다"고 해서 지웠고, 정답 ②(how phenomena are arranged)와 같은 말이라 답을 미리 준 셈이었다.

**Why:** 뒤 문장 내용이나 정답과 같은 말이 칠판에 먼저 나오면 학생이 스스로 모으는 과정이 사라진다. 묶음 이름·캡션은 칠판에서 중요하지 않다.

**How to apply:** 단어 지도는 단어만 쌓고 묶음 이름·아래 한 줄은 웬만하면 안 단다. 라벨을 단다면 그 문장까지 나온 말로만(21번 inventor 쪽 → ·새로움 → ·새로움·진보처럼 단계별). docs/tutor/templates/README.md §1-4. [[type-templates]] [[minimal-highlight]]

**2026-10-18 추가 (23번 피드백 「칠판을 먼저 보여준 이유가 뭐야? 별로 관련 없어 보이는데」):** 질문과 상관없는 칠판을 질문 화면에 띄우지 않는다(단어 하나짜리 「되풀이되는 말」 X, 칠판은 되풀이가 실제로 생긴 뒤부터). 질문 화면 칠판엔 이번에 붙을 말(fresh)이 안 보인다 — session.ts `withoutFresh`가 답하기 전엔 걷어내고 맞히면 붙인다(전 레슨, 테스트 「칠판은 정답을 먼저 말하지 않는다」).

**2026-10-18 (24번 피드백 「여기서 갑자기 칠판 나오는 거 어색해」):** 빈 칠판(칸 이름만, 단어 없음)은 띄우지 않는다. 칠판은 비교할 것이 실제로 둘 다 나온 뒤 설명 화면에서 처음 연다(24번: 공간·시간 칠판은 3문장 뒤 s3_board). session.ts `withoutFresh`가 질문 중 단어를 걷어내 칠판이 비면 칠판째 숨김(그림 칠판·sort 칠판은 둠), 테스트가 막음.
