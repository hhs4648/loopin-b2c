2026-10-14 사용자: 수능 학생은 어렵고 점수가 걸려서 끝까지 보는 참을성이 높다. 그래서 "버튼 20번·5분" 목표가 너무 빡빡한지 고민 중.

**Why:** 길면 이탈하는 게 아니라 "이 시간에 기출 더 풀 걸" 하는 기회비용으로 앱 가치를 판단한다. 아는 걸 다시 듣는 시간이 가장 아깝다.

**How to apply:** 레슨을 줄일 땐 검수한 내용을 지우기보다, 문제 푸는 줄기는 모두에게 / 문법·반복은 `known`·❓칩으로 건너뛸 수 있게. 길이 기준은 "잘하는 학생 기본 줄기 20~25번" 쪽으로 제안함 (사용자 확정 전). 39번 감축 논의에서 나옴. [[reference-lesson-2026-q21]] [[q21-simplify-feedback]]
