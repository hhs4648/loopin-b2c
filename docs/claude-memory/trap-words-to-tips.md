2026-10-16 선생님: 「다 Tip으로 연결해줘」. `content/tutor/word-traps/함정단어.xlsx` → `npm run traps:export` → `traps.json` → 세션이 그 단어가 나오는 문장 화면마다 Tip(`src/tutor/policy/traps.ts`). **사용 O인 것만**(빈 후보는 안 띄움 — 2026-10-16 선생님: 36번 주어진 글 후보 Tip 5개 다 불필요), 「누구에게」에 단계 없으면 안 띄움, 손으로 쓴 같은 단어 Tip이 그 문장에 있으면 그걸 우선. 단어 Tip은 노출 제한 없음. 읽기 화면에도 미리(그 문장에서 뜻을 묻는 단어는 빼고).

**How to apply:** 표시판의 「헷갈릴 곳」을 받으면 엑셀에도 줄을 넣고(사용 O, 메모 「선생님 표시판」) traps:export. 헷갈리는 단어는 기본 Tip만 — 3지 질문은 늘어져서 X(work·manner 질문 지움), 선생님이 메모에 「질문으로」라고 할 때만. [[annotation-tool]] [[key-words-definition]]

**보이는 방식 (2026-10-16 선생님: 모아보기는 양이 많아 안 읽게 된다):** 칩 대신 문장 아래 「자주 헷갈리는 단어 표시하기」 버튼 → 켜면 그 단어에 물결 밑줄, 단어를 누르면 뜻 아래 💡. 기본 꺼짐, 고르는 문제 중엔 버튼 없음.

**자리 (2026-10-16):** 문장 아래 작은 칩 한 줄(🔊 듣기 · / 끊어읽기 · 〰 헷갈리는 단어). 「단어를 누르면 뜻이 나와요」는 칩 줄 아래 작은 글씨로 — 말풍선 안은 X(선생님 말이 아니라 지시문), 단어 수 표시는 뺌.

**2026-10-18:** 3월이 2024·2026 둘이라 문제 칸에 해를 붙인다 — 「2024년 3월 23번」(없으면 「3월」 = 2026). word_traps_export.py가 「YYYY년 M월」을 중분류 제목으로 찾음. mortality(≠morality)를 2024년 3월 23번에 추가(고·중·초).

**헷갈리는 단어 vs Tip (2026-10-20 선생님, 정의):**
- **헷갈리는 단어** = 학생이 평소 아는 뜻과 이 글의 뜻이 다른 단어 (bear 곰 ✕ → 견디다, account 계좌 ✕ → 설명). 엑셀 단어 + 손으로 쓴 Tip 중 `trap: true`(exam_kit `tip(..., trap=True)`)만 「〰 헷갈리는 단어」로 간다.
- **💡 Tip** = 알면 좋지만 수업에서 말하기엔 너무 자세한 것 — 따로 눌러 보게 빼 둔 것 (more A than B, 숙어, 문법 요령). 그 화면의 칩으로만.
- 예전엔 mark가 있는 손 Tip이 전부 헷갈리는 단어로 갔다(41개 레슨 518개) → 2026-10-20 엔진에서 막음. 다른 레슨의 진짜 헷갈리는 단어는 아직 trap 표시가 안 돼 있다(29번·2026-03-38 in that만 함).
- 쉬운 말: 「견주다」 대신 「비교하다」 (학생이 모르는 말 쓰지 않기). [[natural-korean-grammar]]
