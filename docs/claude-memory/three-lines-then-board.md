2026-10-16 선생님(36번 주어진 글 g_value_note 화면 보고): 설명이 길어지니 중간에 칠판으로 핵심어(benefit(이점) 등)와 그림을 써서 표현. **설명·뜻 질문 대사가 3번 이상 이어지면 칠판 활용** — 공통 규칙. 주어·동사 찾기(고르기)는 덜 지루하니 세지 않는다(같은 날 선생님).

**Why:** 말풍선만 이어지면 학생이 흐름을 놓친다. 칠판은 쌓여서 한눈에 보인다.
**How to apply:** story 패널(아이콘+en+ko)을 읽은 데까지만 한 줄씩 쌓고, 설명 대사는 칠판 한 줄 추가로 대신한다. 36번 G_STORY 참고. 다른 레슨은 연속 길이 세어 보니 대부분 넘는다 — 적용 범위는 선생님 확인 대기. [[board-read-so-far-only]] [[lines-core-only]]
