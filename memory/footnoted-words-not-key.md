원자료(모의고사 문제지)에서 지문 아래 `*`/`**`로 뜻을 달아 준 단어는 너무 어려워서 풀어 준 단어일 뿐, 핵심 단어가 아니다. ❓ 개념 칩으로 만들지 않고, 마무리 단어 체크(`key_words`)에도 넣지 않는다. 문장 안에서 눌러 뜻을 볼 수 있게 gloss만 둔다.

**Why:** 2026-10-06 21번 quasi-universal ❓를 사용자가 삭제 요청. 같은 이유로 30번 infinite·blade, 39번 transparent·epistemic을 단어 체크에서 뺐다 (39번 transparent는 정답 단서라 문장 강조·설명에는 남겨 둠).

**How to apply:** `content/tutor/exam-source/<시험>/문제.txt`에서 `*단어:` 목록을 확인하고 해당 문항의 단어는 핵심 목록에서 제외. Tip·설명은 사용자가 따로 요청하면 넣는다(30번 blade Tip은 사용자 요청). [[main-clause-never-faded]]
