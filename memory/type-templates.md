2026-10-14 사용자와 유형별 틀 만들기 시작. 위치 `docs/tutor/templates/`: README.md(공통 틀 — 수업 모양, 문장마다 순서, 화면 규칙, 생성기 도구) + blank.md(빈칸 v0.1).
빈칸 틀의 핵심(사용자가 고른 것): 빈칸 위치만 먼저 짚고(질문 없이, `before_read`) → 처음부터 순서대로 읽으며 재진술 모으기(단어 지도) → 빈칸 문장에 도착해서 「무엇이 와야?」「주장과 같은 쪽?」 → 바꿔 쓴 보기.
다음 유형 순서는 사용자와 정한다(순서·문장 넣기·밑줄·제목·어휘). 틀이 굳으면 생성기 도구를 공용 모듈로 뺀다.

학생 단계 고(1~2)·중(3~5)·초(6~8): 레슨 하나, 스텝 `levels`로 영어 돕는 화면만 나눔(내용 파악 화면은 모두). 빈칸 틀 v1 확정(2026-10-14). 선생님은 검수할 때 **중·초(모든 화면이 보이는 단계)로 본다** — 고 단계 화면은 테스트로 확인해 준다.
