사용자는 한국어로 대화한다. **모든 대답을 한국어로 한다** — 작업 보고, 설명, 질문, 표 전부. 코드·명령어·파일 이름만 원문 그대로.

**Why:** 2026-10-09 사용자가 "모든 대답을 한국말로 해줘"라고 요청 (영어로 보고한 적이 있었다).

**How to apply:** 세션이 이어지거나 요약 뒤에도 한국어 유지. 앱 대사(다정쌤)는 따로 해요체 규칙. [[reference-lesson-2026-q21]]
