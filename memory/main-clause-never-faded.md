콤마 사이라고 다 삽입절이 아니다. **주어와 동사가 있는 메인 문장은 절대 흐림(빼도 되는 삽입) 처리하지 않는다** — 주어가 있는 문장은 항상 중요하다. 흐림은 진짜 삽입(관계절 ", which …,", 동격, 예시 대시)에만.

주어 찾기가 어려운 문장(앞에 To부정사·전치사구가 오는 문장)은: ① 「주어는 무엇일까요?」를 먼저 묻고(민트 「주어 찾기 헷갈려요」 버튼은 2026-10-13 전부 삭제 — 다시 넣지 않는다) ② 맞히든 틀리든 슬래시(/)로 덩어리를 나눠 보여 주고(`display`), 뼈대 칠판 + 강조 두 색(민트 = 주어 아닌 앞 덩어리, 노랑 = 메인 문장).

**Why:** 2026-10-06 39번 2문장에서 사용자가 지적. 학생들이 긴 문장에서 주어를 못 찾는 게 가장 큰 어려움이다.

**How to apply:** 새 문장을 만들 때 콤마 사이를 흐림으로 두기 전에 주어+동사가 있는지 확인. [[reference-lesson-2026-q21]] [[check-grammar-tips-against-haeseol]]
